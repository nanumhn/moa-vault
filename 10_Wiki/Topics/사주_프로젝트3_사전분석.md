# 💡 사주 프로젝트3 — 사전 분석

**목적:** 자율 OS 프로젝트 3 (글로벌 동양식 사주 서비스) 회의의 인풋. 형이 명시한 회사 **월 1000만원 순매출** 목표의 핵심 라인. 회의 직전 직원들이 흡수해서 깊은 토론 가능하게.

---

## 1. 🌍 시장 가설 — 왜 글로벌인가

### Astrology/점성술 글로벌 시장 (검증 가설)
- 미국 Astrology 산업: 수십억 달러 규모 (Co-Star, The Pattern 등 100M+ 다운로드)
- 동양 점성술 = **신선한 차별 콘텐츠** (서구 시장에서 친숙도 낮음 + 호기심 高)
- K-pop / K-drama 후광 효과로 한국발 콘텐츠 수용성 향상
- TikTok / Instagram에서 사주·MBTI류 short content 인기

### 동양 사주의 강점
- **개인 특화** (Tarot은 카드 랜덤, 사주는 생년월일시 기반 — 더 운명론적)
- **문화 깊이** (음양오행, 12지, 십간 — 콘텐츠 깊이)
- **AI와 궁합 ✓** (LLM이 사주 명리학 학습해서 해석 생성 가능)

### 리스크
- 사주의 정확성·진실성에 대한 해석 (엔터테인먼트로 포지셔닝 필요)
- 종교/믿음 충돌 가능 시장 (서구 보수 기독교권)
- 경쟁: Co-Star, The Pattern, Sanctuary 등 강자 존재

---

## 2. 💰 결제: PayPal — 통합 요구사항

### 왜 PayPal인가
- **글로벌 통화·결제 표준** (한국 PG는 글로벌 어려움)
- **신뢰도** — 서구 사용자에 친숙
- **체크아웃 간소** — Express Checkout 1-2 클릭

### 통합 옵션
1. **PayPal Standard** (가장 단순) — 리다이렉트 결제
2. **PayPal REST API + JavaScript SDK** — 사이트 내 결제, UX ↑
3. **PayPal Subscriptions API** — 월 구독 모델 (월 1000만원 매출에 핵심!)

### 기술 메모
- Webhook으로 결제 완료 검증 → 사용자 사주 결과 unlock
- Sandbox 환경 먼저 (개발 자유)
- 한국 사업자 등록 + PayPal Business 계정 필요

## 3. 🎯 차별화 — Co-Star/Pattern을 뛰어넘는 우리만의 카드

1. **동양 사주 = 신선함** — 서구 점성술 대비 차별 콘텐츠 (UVP)
2. **AI 깊이** — LLM이 한지오·이서아처럼 인격으로 사주 해석 (단순 알고리즘 결과 X)
3. **숏폼 적합** — 일일 사주 1분 영상 (Suno BGM + 한지오 카피 + 자동화)
4. **K-Brand 연결** — 음악(P1)·드라마(P2) IP와 연동 가능 (예: "강시우 감독이 추천하는 오늘의 무드")
5. **무료 시드 + 프리미엄** — 매일 짧은 무료 사주 → 상세 분석 / 궁합 / 연간 운세는 유료

## 6. ❓ 회의 직전에 결정해야 할 큰 질문

- **타깃 1순위 시장** — 영어권 전체 vs 미국 단독 vs 동남아 시장
