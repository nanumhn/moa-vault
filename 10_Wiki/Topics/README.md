# 💡 Topics — 도메인 지식

장르·제작기법·마케팅·도구 등 **회사가 일하면서 쌓아가는 도메인 지식**을 주제별로 정리.

## 파일 네이밍

- 한글 또는 영문 슬러그: `시티팝_사운드_스펙.md`, `AI_캐릭터_일관성_LoRA.md`
- 필요 시 메타데이터(YAML frontmatter): `tags`, `author`, `last_updated`

## 갱신 패턴

- 회의에서 새 인사이트 나오면 → 직원이 자신의 `Skills/<id>/`에 먼저 적고 → 일반화될 가치가 있으면 `Topics/`로 승격
- 형이 외부에서 본 좋은 자료 → 직접 정리해서 추가

## 예시 (시드, 아직 없음)
