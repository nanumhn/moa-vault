# 사주 프로젝트3 페이즈2 — 앱 개발 회의 사전 입력

페이즈1 산출물 4종을 페이즈2(앱 개발) 회의 시작 전 한 페이지로 정리. 회의 참석자가 이 문서 한 번만 읽으면 페이즈1 결론을 모두 흡수 가능.

## 페이즈1 결론 한 줄
> **"공감적 발견의 감성 콘텐츠 여정"** — Co-Star/Sanctuary 대비 차별점은 '발견 과정 자체의 시각화'. 단발 $4.99 + 구독 $7.99/월 하이브리드. 1순위 시장 자아탐색 20대 후반~30대 초반 여성. 기준점 시나리오 월 매출 $9,500 (≈ 1,250만원).

## 페이즈2 회의가 결정해야 할 것
1. **기술 스택** — Next.js 16 + ? (DB / 인증 / 사주 엔진 / i18n)
2. **MVP 범위 — 첫 30일 launch 가능한 최소 셋**
   - 페이즈1이 정의한 '오늘의 감성 무드 카드' + 비주얼 티저가 핵심
   - 심층 보고서·다차원 해석 제외
3. **PayPal Subscription + 단발 결제 통합 명세** — Sandbox → Prod, Webhook 검증, 환불 7일 규칙
4. **사주 엔진** — 외부 라이브러리 / 자체 룰 / LLM 텍스트 생성 조합 결정
5. **다국어** — 영어 1순위, 향후 중/일 확장 가능 구조
6. **UI/UX** — '몽환적인 공감' 무드. 첫 화면 1초 인상
7. **QA / 결제 분쟁 시나리오 테스트 플랜**

## 페이즈1 핵심 차별점 (코드/UX에 반영해야 할 것)
- **발견 과정(Process Focus):** 결과만 던지지 말고 사용자가 자기 키워드를 발견하는 시각화 단계 필수
- **공감형 콘텐츠:** 거대한 사주 데이터를 '일상 무드 카드' 작은 단위로 변환
- **비주얼 스토리텔링:** 텍스트보다 시각 티저 + BGM 몰입

## 가격 / 매출 (페이즈1 확정)
- **Tier 1 (Hook):** $4.99 단발 — 첫 진단 리포트
- **Tier 2 (Subscription):** $7.99/월 — 무제한 콘텐츠
- **기준 시나리오:** MAU 4,500 / 단발 전환 15% / 구독 유지 8% → 월 $9,500

## PayPal 통합 명세 (페이즈1 확정 — 페이즈2에서 코드화)
- **Subscriptions API** 메인 (자동 갱신 + 구독 관리)
- 단발은 **REST API** 보조
- Webhook: `Payment Successful` / `Payment Failed` / `Refunded` 실시간 수신 → DB 트랜잭션
- 환불: 7일 이내 사용 취소만 / 이후 환불 불가 약관

## 운영 (페이즈1 확정 — 페이즈2 코드 영향)
- **1인 운영 가능한 MVP 범위** 우선. CS 채널은 이메일 + Discord
- 다국어 핸드오프: 영어 자동 + 한국어 수동
- 결제 분쟁 시나리오 3개 (페이즈1 ops_plan.md 참조) 시뮬레이션 코드 필요

## 마케팅 (페이즈1 확정 — 앱 안에 들어갈 hook)
