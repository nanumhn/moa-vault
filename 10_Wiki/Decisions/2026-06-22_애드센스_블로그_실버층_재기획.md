## 1. 트롯·드라마 니치의 실제 검색수요 (근거)

### 1-1. 왜 시니어 × 트롯/드라마인가

- **트롯 열풍의 실체:** 미스터트롯/미스트롯(TV조선) 이후 트롯은 **중장년·시니어의 메가 팬덤 문화**로 자리잡음. 임영웅·영탁·이찬원·정동원 등 스타 가수의 핵심 팬층이 **40~70대 여성 중심**이며, 이들은 디지털에서 매우 능동적(투표·스밍·검색·커뮤니티). "임영웅 콘서트 일정", "임영웅 근황" 류는 상시 고볼륨 검색.
- **드라마 시청층:** 일일드라마·주말드라마(지상파)·아침드라마의 본방 시청 코어가 **50~70대**. 이들은 "오늘 ○○드라마 몇 시", "○○드라마 몇 회", "그 배우 누구", "줄거리/결말"을 **방영 직후·직전 반복 검색**.
- **시니어 검색 행동의 특성:** ① **편성 반복검색**(매일·매주 같은 걸 다시 검색 → 재방문 트래픽) ② **인물 호기심**("저 사람 누구지?") ③ **다시보기 갈증**(본방 놓침 → "○○ 다시보기"). 이 3가지가 롱테일 검색의 금맥.

## 2. 🔴 애드센스/저작권 리스크 — 안전선 vs 금지선

> **이건 6/21 회의에서 뉴스 큐레이션을 제외한 이유와 똑같은 함정이다.** 트롯/드라마는 "콘텐츠가 곧 저작물"이라, 원문(가사·영상·실황)을 그대로 가져오면 **애드센스 거절/정지 + 저작권 침해(민형사) 리스크**. 반대로 **사실 정보를 자체 문장으로 재구성**하면 안전. 안전선과 금지선을 명확히 긋고, 파이프라인에 **금지선을 하드 룰로 박는다.**

### 2-1. 금지선 (절대 X — 애드센스 정지·법적 리스크)

| 금지 행위 | 리스크 |
|---|---|
| **가사 전문/상당 부분 게재** | 음악 저작권(작사가·협회) 침해. 가사 사이트 외 게재는 위험 |
| **방송 영상 무단 임베드/캡처 양산** | 방송사 저작권 침해. 유튜브 공식 임베드 외 무단 영상·캡처 다수 게재 X |
| **공연 실황 영상·녹화** | 공연 저작권·초상권 침해 |
| **음원 파일/스트리밍 무단 제공** | 명백한 저작권 침해 |
| **불법 다시보기 링크 안내** | 정책 위반 + 방조 책임. "○○ 무료 다시보기" 불법사이트 링크 절대 X |
| **대본/대사 전문 전사** | 극본 저작권 침해 |
| **타 매체 기사 복붙 큐레이션** | 6/21에 제외한 뉴스 큐레이션과 동일 함정 |
| **연예인 사진 무단 대량 게재** | 초상권·사진 저작권. 출처불명 이미지 X |

### 2-2. 안전지대 (O — 사실 + 자체 가공)

| 안전 콘텐츠 | 안전한 이유 |
|---|---|
| **편성표·방영시간 정보** | 사실 정보(저작물 아님), 자체 정리·표로 가공 |
| **출연진 소개(이름·역할·간단 프로필)** | 공개 사실의 자체 서술 |
| **자체 작성 줄거리 요약** | 내가 본 걸 내 문장으로 요약(대본 전사 아님) — 짧고 자체적이면 안전 |
| **관람·시청 가이드** | "어느 채널·OTT에서 정식으로 볼 수 있나"(정식 경로만) |
| **가수 활동 소식 큐레이션** | 콘서트·방송 일정 등 사실의 자체 문장 정리(원문 복붙 X) |
| **OST 곡 정보·정식 음원 링크** | 곡명·가수 사실 + 멜론/유튜브뮤직 공식 링크(가사·음원 게재 X) |
| **공식 유튜브 임베드(허용된 것만)** | 방송사·가수 공식 채널의 임베드 허용 영상만 |
| **자체 의견·감상·정리 글** | 100% 창작 = 가장 안전 + 차별화 |

### 2-3. 운영 하드 룰 (파이프라인에 강제)

1. **LLM 프롬프트에 금지선 명시** — "가사·대사·기사 원문을 절대 인용/복붙하지 말 것. 사실 정보를 네 문장으로만 서술." 시스템 프롬프트 고정.
2. **이미지 정책** — 공식 출처·라이선스 확인된 것만. 기본은 직접 만든 안내 그래픽/표 위주.
3. **다시보기 = 정식 경로만** — 웨이브·티빙·넷플릭스·공식 유튜브 등 합법 경로만 안내. 불법사이트 키워드 자동 차단 리스트.
4. **사람 1포인트 검수에 "저작권 체크"를 명시 항목으로** — 가사/영상/복붙 혼입 여부를 검수 체크리스트에 박는다(애드센스 정지 = 사업 사망이라 이건 양보 불가).

> **COO 판단:** 트롯/드라마는 수요는 최고지만 저작권이 칼날이다. **금지선을 자동화 하드룰로 박고 안전지대만 양산**하면 블루오션. 룰 없이 시작하면 6/21 뉴스 큐레이션과 똑같이 거절당한다.

## COO 코멘트 (정도현)

- **이건 수요로는 역대 최고 니치다.** 트롯 팬덤 + 드라마 시청층은 시니어 디지털 모수의 핵심이고, 편성·출연진·다시보기는 매일·매주 반복 검색되는 재방문 금맥이다. B2B엔 없는 "반복 트래픽" 구조가 생긴다.
- **단, 칼날 위를 걷는다 — 저작권.** 트롯/드라마는 콘텐츠 자체가 저작물이라, 가사·영상·실황·대본을 그대로 가져오는 순간 6/21에 우리가 제외한 뉴스 큐레이션과 똑같이 애드센스 거절·정지·법적 리스크에 빠진다. 그래서 이번 기획의 80%는 **"안전지대만 골라 자체 문장으로 가공"**에 있다. 금지선을 LLM 프롬프트 하드룰 + 검수 체크리스트로 이중 봉인했다.
- **솔직한 단가:** 연예·생활정보라 RPM은 B2B의 1/3~1/2다. 숨기지 않았다. 대신 거대 모수 + 반복 재방문 + 0원 자동화로 절대 수익을 메운다.
- **user_value_first 준수:** 시니어 트롯/드라마 팬에게 불법 다시보기·공포마케팅·과장 정보 유혹이 크다. 절대 안 한다. "정확한 편성·정식 관람 경로를 친절히 정리해주는 신뢰 가이드" 포지션을 끝까지 지킨다 — 신뢰=재방문=수익의 정직한 경로.

**다음 추천 단계:** 액션 1(키워드 실측) + 액션 2(저작권 하드룰 프롬프트 테스트)를 박지원·박나래에게 즉시 병행 할당 → 1일 내 수요 정량 + 안전 양산 검증 → 형 결재(A~E) → W1 셋업 착수.
