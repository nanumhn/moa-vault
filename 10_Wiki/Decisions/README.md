# ⚖️ Decisions — 결정 사항 (감사로그)

**형의 결재** + **회의에서 도출된 결론**을 시간순으로 기록한다. 추후 "왜 이 결정을 했지?"를 추적할 수 있는 회사의 메모리.

## 파일 네이밍

- `YYYY-MM-DD_주제.md` (예: `2026-05-29_드라마기획_결재.md`)
- 같은 날 여러 건이면 뒤에 `_1`, `_2`

## 표준 템플릿

```markdown
---
date: 2026-05-29
type: 형결재 | 회의결론 | 페이즈종료
project: [[Projects/프로젝트2_가족드라마_12부작]]
approver: 형
status: 승인 | 보류 | 반려
---

# 2026-05-29 — 드라마 기획 결재

## 컨텍스트
(왜 결정이 필요했는지)

## 옵션 / 제안
(고려한 안들)

## 결정 사항
(최종 결론)

## 근거
(왜 그렇게 결정했는지)

## 다음 액션
- [ ] 페이즈2 착수
- [ ] 촬영감독 충원

## 관련 자료
- [[../../00_Raw/2026-05-30/run_20260530_032730_드라마기획/]]
- [[Skills/siwoo/]]
```

## 원칙

- **불변 (immutable)**: 결정은 수정하지 않는다. 잘못된 결정이면 새 Decision으로 뒤집기 + 이전 결정 링크
- **검색 가능**: tags + frontmatter로 분류
