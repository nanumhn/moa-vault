1. **nblog-saas 로컬 인프라가 재부팅에 안 살아나던 구조적 결함** — Postgres가 수동 기동 프로세스(zonky embedded-postgres, `pg_ctl.exe`)였고, 로컬 cron 라우트(job-reaper/slot-planner)는 vercel.json 배포 시에만 동작해서 로컬에서는 애초에 아무도 자동 호출하지 않고 있었다. 즉 지금까지 로컬 자동발행은 사람이 직접 눌러야만 돌아갔다. `MoaNblogStackUp`(재부팅 복구)+`MoaNblogCronTick`(1분 주기 로컬 크론 대체)로 수리.

3. **오늘 06:00 aiislife 발행 스킵 원인 2개 중첩** — ①위 인프라 문제 ②어제 E2E 테스트가 운영DB(nblog_dev)에 직접 기록을 남겨 오늘 슬롯을 미리 소비시킴. 후자는 테스트DB 분리가 안 돼 있어서 생긴 문제로, 아직 미수리(다음 과제).

## 배포 방향 전환

nblog-saas를 Vercel Pro($20/월, 크론주기 제약 때문에 필요)가 아니라 형이 이미 운영 중인 AWS Lightsail(toastdm.com)로 배포하기로 확정. 이 서버는 빈 서버가 아니라 pm2로 `homepage-nanumn`·`suno-helper`·`toastdm-backend` 3개가 이미 돌고 있고 RAM 1GB(여유 ~94MB)인 작은 사양 — 기존 서비스 안 건드리고 별도 추가, 부족하면 사양 업그레이드하기로 함.

덱스가 SSH 접속·standalone 빌드·Linux Prisma 엔진까지 준비 완료. 남은 건 형 액션 2개: ① neon.tech 무료 프로젝트 직접 생성(AI가 가입인증 대신 불가) ② DNS `nblog.toastdm.com → 3.37.24.58`.

- 가입 흐름: 초대장 발급 → 이메일 인증 → 체험판. 초대장 등급 4종(3일체험/1개월/1년/프리패스). 체험판 기간 14일 → 3일.

## 검증 성공

nblog-saas 다중계정(aiislife + sky0bada) 동시 운영 페어링 검증 성공 — 한 PC에서 서로 다른 네이버 계정 2개를 동시에 운영할 수 있음을 실증. 로컬 대시보드 로그인이 막혀있던 문제(Google/SMTP 미설정)는 개발용 매직링크-로그출력 우회로 해결(운영 배포 전 반드시 실SMTP로 교체 필요 — 안 바꾸면 가짜가입 구멍).
