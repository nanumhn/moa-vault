## 의사 결정 (자율 채택 — 형 결재 전 자동 처리)

1. **Prisma 7 → 6 다운그레이드** — Prisma 7은 SQLite 어댑터 강제. 시간 손실 크다고 판단해 안정적인 v6 채택. 운영 PG 마이그레이션 시 v7 재검토 가능.
2. **i18n 페이즈 3.7로 미루기** — SNS 카드가 이미 영문/한글 동시 표시. NextAuth 도입 시 사용자 locale 필드 연동으로 자연스러움.
3. **E2E Playwright는 옵션화** — 단위 테스트 13개로 핵심 로직 검증됨. Playwright은 브라우저 설치 시간 큼. 페이즈 4(배포) 시 CI에 추가.
4. **PayPal 통합 a/b 분리** — 코드 골격은 자동 진행 (3.3.a), Sandbox 키는 형 계정 발급 후 (3.3.b).

## 자동 보강 발견 사례
- **page.tsx Phase 3.0 실패** — 초기 작성한 hero가 Write 타이밍 이슈로 디스크에 안착하지 못함. Phase 3.4에서 발견·복구. 빌드는 default boilerplate로 통과해서 늦게 발견.
- **next/og Edge runtime hang** — 한국어 폰트 fetch가 Edge에서 무한 대기. Node.js runtime 전환으로 자동 해결.
