# 10_Wiki — 가공된 지식

`00_Raw/`의 원본을 **큐레이션·연결·요약한 결과**가 여기 산다. P-Reinforce의 "구조화된 지식" 개념을 차용 + 우리만의 `Skills/` (직원별 학습)를 추가.

## 4개 카테고리

| 폴더 | 역할 | 갱신 주체 |
|---|---|---|
| `Topics/` | 💡 도메인 지식 (장르/제작기법/마케팅 등) | 직원 학습 누적 → 자동 + 형 큐레이션 |
| `Projects/` | 🛠️ 프로젝트별 진행/완료 정리 | 페이즈 종료 시 자동 + 비서 정리 |
| `Decisions/` | ⚖️ 형 결재 + 회의 결론 (감사로그) | 결재 시 자동 |
| `Skills/` | 🚀 **직원별** 학습 노트 (자기개선 핵심) | 회의 직후 자동 + 직원 자가 갱신 |

## 위키링크 (Obsidian)

문서 간 `[[연결]]` 적극 사용. 그래프 뷰로 지식의 연결을 시각화.

- 예: `Projects/가족드라마_12부작.md`에서 `[[Topics/AI_캐릭터_일관성]]`을 링크
- 예: `Skills/seoa/시티팝_큐레이션.md`에서 `[[Decisions/2026-05-29_드라마기획_결재]]`를 링크

## 갱신 빈도

이 폴더는 **활발히 변하는** 영역. 회의·결재·작업마다 자동 추가/수정 + 자동 git commit/push.
