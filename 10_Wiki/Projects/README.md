# 🛠️ Projects — 프로젝트별 정리

회사가 진행한/진행 중인 **프로젝트 단위 정리**. 페이즈가 끝날 때마다 자동으로 한 줄씩 늘어난다.

## 파일 1개 = 프로젝트 1개

각 프로젝트 파일에 들어가는 표준 섹션:

```markdown
---
status: planning | producing | published | archived
phases: { 1: completed, 2: in-progress, 3: pending }
started: 2026-05-29
last_updated: ...
---

# 프로젝트 N — (이름)

## 개요
(한 문단)

## 단계별 진행
- 페이즈 1: [[Decisions/...]] 결재 완료
- 페이즈 2: [[Skills/siwoo/...]] 촬영 디렉팅 중
...

## 산출물
- [[../../00_Raw/2026-05-30/...]] 회의 원본
- (영상/곡 링크)

## 다음 액션
...
```

## 현재 프로젝트

- `프로젝트1_Suno_음악_파이프라인.md` (운영 중)
- `프로젝트2_가족드라마_12부작.md` (페이즈1 완료, 2 대기)
