## 2. A. Saju Tarot — 타로 덱

### 2.1 브랜드명 (최종 추천)

- **확정안: `CELESTIAL PILLARS`** (서브: *Saju Tarot — The Four Pillars Oracle*)
  - 사주 = 四柱(Four Pillars)의 직역이 그대로 신비롭고 글로벌하게 읽힘
  - "Celestial"(천체) = 천간·지지·별자리 톤과 정합, 영성 시장 키워드
  - 도메인 후보: `celestialpillars.com` / `.co` / `fourpillarsoracle.com` (※ 실제 가용성은 레지스트라 검색 필요 — 비-.com은 rdap 신뢰 불가, 메모리: reference_domain_availability_check)
- 백업안: `OROORA` (오행 Oh-haeng 음차 + Aura) / `JIJI ORACLE` / `THE GANJI DECK`

### 2.2 카드 구성 — **78장 (타로 표준 정합)**

> **설계 원칙: 타로 컬렉터가 "익숙한 구조"로 받아들이되, 내용물은 100% 사주.** 78장은 Etsy/Printful 타로 카테고리의 표준 → 검색·판매·POD 템플릿 호환 최상.

| 구획 | 장수 | 사주 매핑 | 비고 |
|---|---|---|---|
| **Major Arcana (천·지)** | **22** | 천간(天干) 10 + 지지(地支) 12 = 22 | ★타로 메이저 22장과 정확히 일치 — 핵심 세일즈 포인트 |
| **Minor Arcana (오행 4×슈트)** | 40 | 오행 중 4원소(목·화·금·수)를 4개 슈트로, 각 1~10 | 타로 4슈트(완드/컵/소드/펜타클) ↔ 목/수/금/화 매핑 |
| **Court Cards (사주 십성·궁)** | 16 | 4슈트 × 4코트(Page/Knight/Queen/King ↔ 십성·궁) | |
| **합계** | **78** | | 표준 타로 1:1 호환 |

- **오행 5번째 "토(土)"** 는 덱의 **중심/공집(空)** 으로 → 별도 **"The Earth Pillar" 스페셜 카드 1장**을 보너스로 동봉(79장 한정판 앵글). 토=중앙·균형의 상징을 마케팅화.
- 60갑자(천간10×지지12)는 **개인화 리딩(2.4 수익라인)** 의 백엔드 데이터로 활용 → 카드 22장 + 60갑자 해석 엔진.

### 2.3 성인(어덜트) 타겟 앵글

> **"어덜트 = 성적인 것이 아니라, 깊이·성숙·자기직면."** (형 지시 명확 반영)

- **3대 정서 축:** ① 신비주의(Mysticism) ② 명상·내면(Meditation/Shadow work) ③ 자기발견(Self-discovery)
- 톤: 고요한 인디고·골드, 동양 수묵 × 코스믹. 선정성 0, 폭력성 0. "성숙한 어른의 영적 도구".
- 카피 톤 예시: *"The 4 Pillars you were born under. Read the sky you came from."*
- 차별화: 서양 타로는 78장 = 인생 원형. **우리는 거기에 "당신의 생년월일시 = 당신만의 4기둥"** 이라는 **개인화 레이어**를 얹는다(서양 타로에 없는 사주 고유 강점).

## 3. B. Five Phases — 사주 전략 카드게임 (성인용)

### 3.1 게임명 (최종 추천)

- **확정안: `FIVE PHASES`** (서브: *A Game of Elemental Destiny* / 오행쟁패)
  - "Five Phases" = 오행(五行)의 정식 영어 학술 번역 → 진지·성숙·검색 친화
- 백업안: `WUXING` (음차) / `CYCLE OF FIVE` / `SAENG-KEUK` (상생상극)

### 3.2 게임 컨셉 — 오행 상생·상극 엔진

> **포켓몬(라이트)이 아니라 Magic: The Gathering / 7 Wonders 톤의 깊은 전략.**

- 코어 룰: **오행 상생(相生) = 자원 생성, 상극(相剋) = 공격/카운터.**
  - 상생 사이클: 목→화→토→금→수→목 (생성/버프)
  - 상극 사이클: 목剋토, 토剋수, 수剋화, 화剋금, 금剋목 (파괴/카운터)
- 승리 조건: 자신의 **"4기둥(Four Pillars)"** 을 먼저 완성(년·월·일·시 4슬롯 채우기) OR 상대 기둥 붕괴. → A 브랜드의 4기둥 세계관 그대로 차용.
- 인원/시간: 2~4인 / 30~50분 / 룰 난이도 중상(겜성 깊이).

### 3.3 카드 구성

| 카드군 | 장수(예시) | 설명 |
|---|---|---|
| **오행 캐릭터 카드** | 5속성 × 10 = 50 | 목/화/토/금/수 속성 유닛. 공/방/특수능력. (A덱 아트 재활용) |
| **행동(Action) 카드** | 30 | 상생 부스트, 상극 카운터, 자원 전환 |
| **운세 이벤트(Fortune) 카드** | 20 | 60갑자 기반 랜덤 이벤트(대운/세운 모티프) — 판도 뒤집기 |
| **기둥(Pillar) 카드** | 4종 세트 ×인원 | 년·월·일·시 슬롯 보드 |
| **합계(베이스 세트)** | **약 100~110장** | 확장팩 여지 |

### 3.4 성인 앵글

- 깊은 의사결정 트리(상생/상극 + 운세 변수) → **"한 판이 사주 한 인생"** 컨셉. 카지노틱 운+전략의 균형.
- 아트: A의 인디고·골드 코스믹 그대로 → 성숙한 비주얼 일관성. 가족용 아님, 보드게이머 타겟.
