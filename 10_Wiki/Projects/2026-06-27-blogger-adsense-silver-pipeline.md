# Blogger 애드센스 실버 블로그 — 실행 기획서

> **이 문서의 위치:** 2026-06-22 "실버층 × 트롯/드라마 재기획(피벗 v2)"의 **콘텐츠 전략은 그대로 승계**하고, **게시 플랫폼만 WordPress → Blogger(Google)로 전환**한 실행 기획서다. 콘텐츠 안전선(저작권)·타깃·키워드 전략은 v2를 정본으로 따르며, 본 문서는 (1) Blogger 전환의 근거·셋업 (2) 애드센스 승인 로드맵 (3) n8n→Blogger API 자동화 구조 (4) 수익·일정·리스크를 실행 단위로 구체화한다.
>
> ⚠️ **본진 분리 원칙:** k-saju.me 및 blog.k-saju.me(Next.js+MDX)는 **그대로 유지**. 본 Blogger 블로그는 **실버 트롯/드라마 전용 애드센스 라인으로 완전 분리** 신설한다. 두 자산을 섞지 않는다(SEO·브랜드·정책 리스크 격리).

## 0. 결론 요약 (TL;DR)

- **틈새:** 한국 시니어(5060+, 코어 60대) × 트롯·드라마의 **"편성·출연진·다시보기·가수 일정" 사실정보 가이드.** 콘텐츠가 곧 저작물인 영역이라 **저작권 안전선이 사업의 생명선** — 가사·영상클립·실황·방송캡처는 절대 금지, 편성/출연진/자체요약/정식 관람 가이드만 허용.
- **왜 Blogger:** 구글 소유 → 애드센스 승인·연동이 가장 매끄럽고, 호스팅 무료·인덱싱 빠름·코드배포 0. 시니어 타깃 정보형 양산 블로그에 최적. 본진(Next.js)은 개발 유연성 유지, 애드센스 라인만 운영 부담 0인 Blogger로 분리.
- **승인 타임라인 [추정]:** Blogger 셋업(W1) → 안전지대 글 20~25편 축적(W1~W3) → 커스텀 도메인 연결 + 필수 페이지 완비 후 애드센스 신청(W3 말) → 심사 **2~4주**(첫 신청 거절 가능성 고려, 보강 후 재신청 시 누적 4~8주). **도메인 연령 1~3개월**이 권장이라 신청 시점은 보수적으로 잡는다.
- **수익 추정 [추정]:** 단독 라인 아님. 보수 M6 ≈ 15~45만원 / 기본 M12 ≈ 50~110만원 보조 라인(2026-06-22 v2 추정 승계, 한국 정보형 RPM $0.8~$2.5 가정). 2,000만원 KPI에서 **애드센스 축의 역할은 "API 비용 0의 복리형 베이스 트래픽 라인"** — 절대액보다 무비용·재방문 구조가 가치.
- **형이 할 것(딱 3가지):** ① Blogger 블로그 생성(구글 계정) ② 커스텀 도메인 구매+연결 ③ 구글 OAuth(Cloud Console 클라이언트 + 애드센스 신청 클릭). 나머지(콘텐츠 전략·n8n 워크플로우·프롬프트·검수)는 클로/서아/나래.

## 1. 틈새·포지셔닝 확정 (저작권 안전선)

### 1-1. 타깃 & 포지션
- **타깃:** 한국 시니어 50~70대(코어 60대), 트롯 팬덤 + 일일·주말드라마 시청층. 디지털에서 능동적(검색·투표·커뮤니티).

> **운영 헌법(파이프라인 하드룰):** ① LLM 시스템프롬프트에 "가사·대사·기사 원문 절대 인용금지, 사실을 네 문장으로만" 고정 ② 이미지는 직접 만든 안내그래픽/표 기본 ③ 다시보기=정식경로만(불법 키워드 자동 차단 리스트) ④ 사람 1포인트 검수에 **"저작권 혼입 0" 체크 항목 필수**(애드센스 정지=라인 사망이라 양보 불가).

## 3. Blogger + 애드센스 승인 로드맵

### 3-1. 왜 Blogger인가 (WordPress 대비)
| 항목 | Blogger | WordPress(구안) |
|---|---|---|
| 애드센스 연동 | 구글 소유 → 가장 매끄러움, 콘솔 통합 | 별도 연동·플러그인 |
| 호스팅 비용 | **무료** | 월 0.5~2만원 |
| 코드 배포 | 불필요(콘솔 게시) | 테마·서버 관리 |
| 인덱싱 | 구글 친화 빠름 | 보통 |
| API 자동화 | Blogger API v3(REST, OAuth2) | WP REST API |
| 단점 | 디자인 자유도·소유권 제약(플랫폼 종속) | 자유롭지만 운영비·관리 |

→ 애드센스 단일 목적 + 시니어 정보형 양산엔 **Blogger 장점이 단점을 압도**. (디자인 한계는 시니어 가독성 테마로 충분 커버.)

### 3-2. Blogger 셋업 절차
1. 구글 계정으로 blogger.com → 새 블로그 생성(제목·blogspot 주소).
2. **시니어 가독성 테마** 선택 + 본문 글씨 크게/고대비/넓은 행간. 모바일 우선(시니어 다수 모바일).
3. **필수 페이지 4종**(애드센스 승인 필수): 소개(About) · 개인정보처리방침(Privacy Policy) · 연락처(Contact) · 면책고지(Disclaimer, 저작권·정보 정확성). → 클로가 초안 작성, 형이 게시.
4. **커스텀 도메인 연결**(권장): blogspot 서브도메인보다 커스텀 도메인이 승인·SEO·신뢰에 유리. 한글 직관 도메인 후보 3개 W1 제출(연 1~2만원). DNS는 Blogger 안내(CNAME 2개) 그대로.
5. 검색 콘솔 등록 + sitemap 제출(인덱싱 가속).

### 3-3. 애드센스 승인 요건 (2026 기준 [추정 포함])
- **글 수:** 공식 고정수치 없음. 실무 벤치마크 **고품질 20~25편**(신청 전). 각 글 **800~1,200자+** 본문, 소제목·표·자체 정리 포함.
- **콘텐츠 품질:** 원본·고유·사용자 가치. 사실 나열 복붙 NO → 자체 정리표 + 한 줄 코멘트로 고유성 확보.
- **필수 페이지:** 소개·개인정보·연락처·면책 완비.
- **도메인 연령:** 커스텀 도메인 **1~3개월** 권장(신생 도메인 즉시 신청은 거절 흔함). → 현실적 신청 시점은 도메인 구매 후 최소 몇 주~1개월.
- **정책 준수:** AdSense Program Policies + 저작권(섹션 1-3 하드룰이 곧 이 방어막).
- **연령/계정:** 만 18세+ 구글 계정.

### 3-4. 예상 타임라인 [추정]
| 단계 | 시점 | 내용 |
|---|---|---|
| 셋업+글 축적 | W1~W3 | Blogger 생성·필수페이지·글 20~25편 |
| 신청 | W3 말~W4 | 도메인 연결+페이지 완비 후 애드센스 신청 |

## 4. n8n 자동화 구조 설계 (k-saju-blog → Blogger API 전환)

> 기존 자산: n8n(Docker, 포트 5678) + qwen2.5-7b-instruct(LM Studio 1234, API비용 0) + 디스코드 검수 게이트. **파이프라인 골격은 그대로, 게시 노드만 WordPress REST → Blogger API v3로 교체.**

### 4-1. 파이프라인 흐름
```
Cron 트리거(랜덤 시각)
  → 키워드 큐 선택(트롯/드라마 롱테일, 시의성 우선)
  → qwen2.5-7b 초안 생성 [저작권 하드룰 시스템프롬프트]
  → 마크다운→HTML 변환 + 시니어 가독 포맷(큰 글씨·표)
  → humanize-korean(AI티 제거) 후처리
  → 디스코드 #blog 검수 게이트 [저작권 혼입 0 + 팩트 1차확인]
  → 승인 시 Blogger API v3 posts.insert(OAuth2)로 게시
  → 디스코드 발행 알림 + 발행 로그 기록
```

### 4-2. WordPress→Blogger 교체 핵심 (게시 노드만)
- **엔드포인트:** `POST https://www.googleapis.com/blogger/v3/blogs/{blogId}/posts` — body에 Posts 리소스(title·content[HTML]·labels).
- **인증:** n8n Credentials → **Blogger OAuth2 API**. Access Token URL `https://oauth2.googleapis.com/token`. Google Cloud Console에서 OAuth 클라이언트(Client ID/Secret) 발급 + Blogger API 사용설정 + 동의화면.
- **노드 옵션 A(권장):** n8n 기본 HTTP Request 노드 + OAuth2 자격증명으로 직접 호출(의존성 최소, 컨트롤 최대).
- **노드 옵션 B:** 커뮤니티 노드(`@hienhoceo/n8n-nodes-blogger` 등) — 편하지만 외부 의존. 1순위는 A.
- **나머지 노드(Cron·LLM·변환·검수·알림)는 변경 없음** — k-saju-blog 워크플로우 복제 후 게시 노드만 스왑.

### 4-3. 발행 빈도·시각 랜덤화 (인스타 Meta 차단 교훈 반영)
- **빈도:** 초기 W1~W3은 승인용 축적이라 하루 1~2편 꾸준히. 승인 후 하루 1~3편 변동.
- **시각 랜덤화:** Cron 고정시각 금지. 매 실행 ±수십분 지터 + 발행 간격 불규칙(봇 패턴 회피, 자연 트래픽처럼). [[reference_n8n_ig_meta_block]] 교훈 승계.
- **팩트 시의성:** 편성·일정은 틀리면 신뢰 추락 → 검수에서 시간·채널·날짜 1차 확인 필수(생략 금지).

### 4-4. 역할 분리 — 형 vs 클로
| 형(계정·결제·승인만) | 클로/팀(전부) |
|---|---|
| Blogger 블로그 생성(구글 계정) | 콘텐츠 전략·키워드 큐·프롬프트 설계 |
| 커스텀 도메인 구매+DNS 연결 | n8n 워크플로우 구축(게시 노드 Blogger 전환) |
| Google Cloud Console OAuth 클라이언트 생성 + Blogger API 사용설정 | OAuth 자격증명 n8n 등록·테스트(키는 형이 입력, 클로 미보관) |
| 애드센스 신청 클릭 + 승인 코드 게시 | 필수페이지 초안·테마 가독성 설정 가이드 |
| (키·시크릿은 형이 직접 입력, 채팅·vault·git 노출 0) | 검수 게이트·발행 로그·시각 랜덤화 로직 |

## 5. 수익 추정 [추정] + KPI 기여도

> 모두 **[추정]**(실측 0). 한국 연예·생활정보 RPM은 저단가라 보수적으로 잡는다. RPM $0.8~$2.5/1000PV, 신규 블로그 점진 성장 가정. 2026-06-22 v2 추정을 Blogger로 승계(호스팅비 0이라 순수익은 v2보다 약간 유리).

### 5-1. 트래픽 가정별 월 수익 [추정]
| 시나리오 | 가정 | 월 PV[추정] | RPM[추정] | 월 수익[추정] |
|---|---|---|---|---|
| **보수** | 승인 직후~M3, 느린 인덱싱 | 5천~2.5만 | $0.8~$1.5 | 약 0.7~16만원 |
| **기본** | M6 안착, 편성 재방문 정착 | 8만~18만 | $1~$2.5 | 약 **15~45만원** |
| **낙관** | M12, 토픽클러스터 + 시즌 트롯특수 | 25만~60만 | $1~$2.5 | 약 **50~110만원** |

### 5-2. KPI 2,000만원 기여도
- **애드센스 축의 역할:** 단독 라인 아님. M12 기본~낙관 기준 **월 50~110만원 ≈ KPI의 2.5~5.5%** 보조 라인. 절대액보다 **"API 비용 0 + 편성 반복검색 재방문 = 무비용 복리형 베이스 트래픽"** 구조가 본질 가치.
- **업사이드:** 트롯/드라마 팬덤 트래픽 → 콘서트 티켓·굿즈 제휴, 상조·보험 CPA 결합 여지(단 다크패턴·공포마케팅 금지).
- **다운사이드:** 저작권 룰 위반 시 애드센스 정지 = 라인 사망 → 섹션 1-3 하드룰이 수익보다 우선.

### 5-3. 방문 1인당 가치 — k-saju 구독유입과 성격 비교
| | Blogger 애드센스 | k-saju 구독유입 |
|---|---|---|
| 수익 성격 | **광고 노출/클릭**(트래픽 자체가 돈) | **결제 전환**(방문이 구매로 이어져야 돈) |
| 방문 1인 가치 | 매우 낮음(RPM $1~2.5 → 1방문 ≈ 1~3원[추정]) | 높음(전환 1건당 수천~수만원) |
| 최적 KPI | **볼륨·재방문**(허영 아님, 광고는 PV가 곧 매출) | **전환율·LTV** |
| 트래픽 질 | 양 위주 OK(시니어 정보 소비) | 결제의향 높은 질 위주 |

> **유입 책임자 관점:** 애드센스 라인에선 PV가 곧 매출이라 **볼륨이 정당한 목표**(허영 지표 아님). 단 k-saju 유입과 절대 혼동 금지 — k-saju는 전환되는 질이 목표, 애드센스는 광고노출 볼륨이 목표. **두 라인의 유입 전략·측정을 분리**해 운영한다.

## 6. 실행 일정 (W1~W4, owner 지정)

| 주차 | 액션 | owner |
|---|---|---|
| **W1** | 키워드 30개 실측(네이버 키워드도구·구글트렌드) + 검색량 우선순위 재정렬 | **나래**(설계)·**지원**(실측) |
| W1 | 커스텀 도메인 후보 3개 제출 → 형 선택·구매 | 나래 제안 / **형** 구매 |
| W1 | Blogger 블로그 생성 + 시니어 가독성 테마 설정 | **형**(생성) / 클로(테마 가이드) |
| W1 | 필수 페이지 4종(소개·개인정보·연락처·면책) 초안 | **서아**(작성) / 형(게시) |
| W1 | 저작권 하드룰 시스템프롬프트 작성 + 테스트 글 3편 생성·검수 | **나래**(프롬프트)·**서아**(제작) |
| **W2** | 안전지대 글 8~10편 발행(수동/반자동, 품질 우선) | **서아**(제작)·나래(검수) |
| W2 | n8n 워크플로우 복제 + 게시 노드 Blogger API v3로 전환(빌드만, OAuth 대기) | 클로(CTO 협업) |
| W2 | Google Cloud Console OAuth 클라이언트 + Blogger API 사용설정 | **형**(콘솔) / 클로(가이드) |
| **W3** | 글 누적 20~25편 도달 + 검색콘솔 sitemap 제출 + 인덱싱 확인 | 서아·나래 |
| W3 | OAuth 자격증명 n8n 등록·게시 테스트(1편 자동발행 성공 확인) | 클로 / 형(키 입력) |
| W3 말 | 애드센스 신청(도메인 연령·페이지·글수 요건 충족 확인 후) | **형**(신청 클릭) |
| **W4** | n8n 자동화 가동(시각 랜덤화) + 발행 로그·검수 게이트 정상화 | 클로·나래 |
| W4 | 승인 대기/거절 시 보강 루프 + data-finance 첫 트래픽 스냅샷 | **지원**(실측)·나래 |

> 애드센스 승인은 W4 내 보장 불가(심사 2~4주). W4는 "자동화 가동 + 신청 완료" 상태가 목표, 승인 자체는 그 후 도래.
