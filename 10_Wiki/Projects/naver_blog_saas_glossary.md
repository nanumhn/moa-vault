# 네이버 블로그 SaaS — 용어집

형 지시(2026-08-09): 새 개념/객체가 나올 때마다 이름을 확정하고 여기 기록한다. "관리자 툴/대시보드" 같은 말이 뒤섞이면 혼란스러우니, 확정된 용어만 쓴다.

## 확정된 용어

| 용어 | 뜻 | 확정일 |
|---|---|---|
| **관제센터** | 서버 쪽 관리자 대시보드 화면(잡 현황·에이전트 상태 등을 보는 화면) | 2026-08-09 |
| **발행 에이전트** | 사용자 PC에 설치되는 Electron 프로그램. 전용 크롬 프로필로 네이버에 실제 로그인해 글을 올린다 | 2026-08-09 |

## 미정 (다음에 확정 필요)

| 코드/개발상 임시명 | 뜻 | 비고 |
|---|---|---|
| 페어링(pairing) | 발행 에이전트를 서버 계정에 최초 연결하는 절차(1회용 코드) | 사용자 대면 용어로 뭐라 부를지 미정 |
| 잡(job) | 서버가 에이전트에게 내리는 개별 발행 작업 단위 | |
| 슬롯(slot) | 블로그당 하루 발행 가능 자리(최대 2회·12시간 간격) | |

## 규칙
- 새 개념이 코드/기획에 등장하면 바로 형에게 후보 이름을 던지고 확정받는다.
- 확정되면 이 표에 즉시 추가하고, 이후 보고·코드 주석·문서 전부 이 이름으로 통일한다.
