## 3. 월 1,000만원 도달 경로 산식

```
MRR = 월 UV × 가입율 × trial율 × (trial→paid) × ARPU ÷ (1 - 잔존효과)
간이: 필요 활성 유료 = 목표MRR ÷ ARPU = $7,500 ÷ $7.5 = 약 1,000명 결제 슬롯
실제 활성 유지 필요수 ≈ 880~940명 (단발매출 보조 반영 시 880)
```

신규 유료/월 흐름 산식:
```
신규 유료 = UV × 가입율 × trial율 × (trial→paid)
정상상태 활성 = 신규유료 ÷ churn   (유입=이탈 균형점)
```

### 시나리오 비교 (정상상태 880명 유지에 필요한 월 UV)

| 변수 | 기준 시나리오 | 보수 시나리오 |
|---|---|---|
| 가입전환율 | 4% | 3% |
| trial 시작율 | 30% | 25% |
| trial→paid | 40% | 35% |
| churn | 10%/월 | 12%/월 |
| 신규유료 1명당 필요 UV | ~208 UV | ~381 UV |
| 880명 유지 필요 신규/월 (=churn보충) | 88명 | 106명 |
| **필요 월 UV [추정]** | **~18,300/월** | **~40,400/월** |

> 정상상태 기준이라 §2의 "누적 도달 UV(110K)"와 다름:
> §2는 초기 빠른 성장 곡선 가정(신규>>이탈), 여기는 880명을 churn만 메우는 균형점.
> 즉 **880명을 일단 쌓는 데 UV가 많이 들고, 유지엔 UV 18K~40K면 됨.** 누수(churn) 줄이는 게 ROI 큼.

### 갭 귀속 (CSO가 어디를 때릴지)
- 유입 부족: UV 자체가 모자라면 → growth(숏폼·SEO)
- 전환 부족: UV는 있는데 가입/T→P 낮으면 → sales(랜딩·온보딩·결제 UX)
- 이탈 과다: churn 10%↑면 → 리텐션(주간 운세 알림·연간운세 등 재방문 훅)
