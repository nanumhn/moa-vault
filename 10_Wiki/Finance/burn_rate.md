## 6. 런웨이 계산기 — 형이 넣을 숫자는 딱 **하나**

런웨이는 우리 시스템에서 산출 불가하다. **현재 가용 운영자금 Y**는 형 개인 재무정보이고 우리 어디에도 없다.

```
런웨이(개월) = Y ÷ 월 번레이트
런웨이(주)   = 런웨이(개월) × 4.345
```

**형은 Y 하나만 알려주시면 됩니다.** 아래 표에서 바로 읽어도 됩니다.

| 가용자금 Y | X=₩47만 (확인분만) | X=₩55만 (중앙) | X=₩65만 (미확인 포함 상한) |
|---|---|---|---|
| **₩100만** | 2.1개월 / **9주** | 1.8개월 / **8주** | 1.5개월 / **7주** |
| **₩300만** | 6.4개월 / **28주** | 5.5개월 / **24주** | 4.6개월 / **20주** |
| **₩500만** | 10.6개월 / **46주** | 9.1개월 / **40주** | 7.7개월 / **33주** |
| **₩1,000만** | 21.3개월 / **93주** | 18.2개월 / **79주** | 15.4개월 / **67주** |
| **₩2,000만** | 42.6개월 / **185주** | 36.4개월 / **158주** | 30.8개월 / **134주** |

> 전제: **매출 0 지속** 가정. 매출이 생기면 분모가 줄어 런웨이는 그만큼 늘어난다.
> 예) 월 매출 ₩20만이 붙으면 X=₩55만 → X=₩35만이 되어 런웨이가 **57% 길어진다.**

### 자동화 제안 (cto-seojin 협의 필요)
현재 번레이트는 **수동 재측정**이어야 한다. 자동화하려면:
1. Gumroad 매출 조회 스크립트 → 주간 스냅샷에 자동 반영 (오늘 방식 그대로 스크립트화 가능)
