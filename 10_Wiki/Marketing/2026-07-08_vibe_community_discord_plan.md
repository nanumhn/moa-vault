# 바이브코딩 커뮤니티 디스코드 서버 — 기획 설계도

- 작성: growth-head-narae / 2026-07-08
- 목적: 모아 스튜디오 AI 바이브코딩 세미나(형=강사·오프라인·5만원)의 **집객·리텐션 커뮤니티** 구축
- 퍼널 위치: 당근 '혜화 AI 뚝딱 모임'([[2026-07-07_karrot_moim_pack]]) → 무료 번개 → **[이 디스코드 = 지속 커뮤니티]** → 세미나 5만원([[2026-07-05_seminar_landing_curriculum]]) → 심화 강의
- 서버 3역할: (1) 상단 깔때기(관심자 유입·머무름) (2) 세미나 수강생 리텐션·후속학습 (3) build-in-public(모아 브랜드 노출)
- 벤치마크: '바이브 코딩 코리아' (온보딩→소통→라이브음성+역할등업 패턴)
- 브랜드: 대외 명칭 "모아 스튜디오/모아". 내부 닉네임 '클로' 절대 노출 금지.

## 0) 설계 대원칙 (리서치 근거 반영)

리서치에서 확인된 핵심(출처 하단):
- **구조화된 온보딩 = 첫주 리텐션 80%↑**. 첫 **10분**이 "머물지 말지" 결정 골든타임.
- **온보딩은 짧게** — 규칙 1개 + 역할 선택 1개로 시작. 질문은 최대 3~5개. 과하면 진입 전 이탈.
- **채널 과다 = 죽은 채널·썰렁함.** 초기 슬림 → 활동 차면 확장.
- 좋은 첫주 리텐션 30~40%, 40%+면 예외적 우수.

→ 우리 원칙: **① 슬림 오픈(죽은 채널 방지) ② 온보딩 3분 컷 ③ 벤치마크 취사선택(그대로 복제 X) ④ 다크패턴·강제·공포마케팅 금지, 사용자 가치 우선.**

## 1) 서버 채널 구조 청사진

| | `#규칙` | 커뮤니티 규칙. (읽기전용) 온보딩 동의 지점 |
| | `#자기소개` | 자기소개 작성 → **정회원 자동 등업** 트리거 채널 |
| 💬 **커뮤니티** | `#자유수다` | 아무거나 잡담. 커뮤니티 심장. AI·일상 무관 OK |
| | `#질문방` | AI·바이브코딩 막힌 것 질문. "초보질문 환영" 명시 |
| | `#자랑방` | 만든 결과물 자랑(스샷·링크). 리텐션 최강 채널 |

## 2) 역할(Role) 설계

**슬림 4단계.** (벤치마크식 복잡한 등급 X — 리서치: "복잡한 역할 시스템"은 흔한 실패 요인)

| 역할 | 획득 방식 | 보이는 채널/권한 | 색/표시 |
|---|---|---|---|
| **@뉴비** | 서버 입장 시 자동 부여 | 커뮤니티 채널 **읽기 가능(눈팅 OK), 글쓰기는 정회원부터** | 무색 |
| **@정회원** | `#자기소개` 글 작성 시 **자동 등업** | 커뮤니티·라이브 전 채널 개방 | 초록 |
| **@수강생** | 세미나 결제·참석 확인 후 수동 부여 | + `#수강생-전용` `#세미나 자료방` | 파랑 |
| **@멘토(재능기부)** | 형 지정(당근 재능기부·적극 도움 멤버) | 질문방 알림 우선, 이벤트 안내 권한 | 보라 |
| **@운영(모아)** | 형 + 모아 봇 | 전체 관리 | 빨강 |

**등업 로직 핵심:** @뉴비는 커뮤니티 채널을 **눈팅은 되지만 글은 못 쓰게(읽기 전용)** → 자기소개를 쓰면 글쓰기가 열리는 보상 구조. 자기소개가 자연스러운 "첫 행동"이 되고, 눈팅으로 분위기를 먼저 보게 해 진입장벽은 최소, 스팸은 방지. (가시성=보기 ON / 게이팅=글쓰기 권한, 한 방향 통일 — STEP4 item6과 동일.)

> **★로드맵 확정 — @고급멤버 등급 (2026-07-08 형 지시, 나중 도입):**
> 형 아이디어 = 정회원 위에 **@고급멤버(고급자료·고급케어 혜택)** 등급 추가. 방향 확정(활동 열심히 하는 멤버 보상 + 유료 전환 유인). **단 지금은 도입 안 함** — 오픈 초기(멤버 0~50)엔 빈 등급이 김 빠지게 하고, "고급자료·고급케어"라는 실제 혜택 콘텐츠가 아직 없음. **도입 트리거: 활성멤버 밀도(예: 활성 30명+) + 고급자료/케어 콘텐츠 준비 완료 시.** 그 타이밍이 오면 **클로가 먼저 형에게 "지금이 고급멤버 도입 타이밍"이라고 제안**할 것(형이 "꼭 기억했다가 의견 줘"라고 명시 강조). 지금 오픈은 정회원·수강생·멘토 3개로 슬림 시작.

## 4) 운영 봇 추천 (무료 우선)

| 봇 | 역할 | 무료로 가능? | 우리 용도 |
|---|---|---|---|
| **Discord 기본 온보딩/Server Guide** | 규칙동의·역할질문·채널추천 | ✅ 100% 무료(네이티브) | 1순위. 커뮤니티 서버 설정 시 활성화. 외부봇 없이 규칙동의+시작가이드 커버 |
| **Carl-bot** ⭐(내가추천) | 자기소개 작성→자동등업, 리액션롤, 웰컴, 모더레이션 | ✅ 무료티어 매우 넉넉(리액션롤 사실상 무제한) | 2순위 핵심. "자기소개 채널 글쓰면 @정회원 부여" 자동화 |
| **MEE6** | 웰컴·레벨·모더레이션 | △ 무료 제한 많음(리액션롤 등 유료 유도) | 대안. 레벨링 원하면. 단 무료 제약 커서 Carl-bot 우선 |
| **Dyno** | 모더레이션·자동응답 | ✅ 무료 넉넉 | 스팸 심해지면 보조 모더레이션용 |

**추천 스택: Discord 네이티브 온보딩 + Carl-bot 2개면 충분.**
- 네이티브 온보딩 → 입장 규칙동의·시작가이드
- Carl-bot → ① 웰컴 메시지 ② **`#자기소개` 채널 글 작성 감지 → @정회원 자동부여** ③ 기본 자동모더레이션(욕설·초대링크 필터)

**설정 주의(리서치):** 봇 역할을 부여할 역할보다 **위에** 배치(서버설정>역할 드래그), 봇에 "역할 관리" 권한 부여. 안 그러면 자동등업 실패.

> **등업 방식 = A안 확정(자기소개 글쓰면 @정회원 자동등업).**
> - 이유: §3 공개 카피(규칙·웰컴)가 모두 "**#자기소개 쓰면 커뮤니티가 전부 열려요**"라고 약속 → 실제 게이팅도 A여야 카피와 동작이 일치한다. B(규칙방 ✅ 등업)로 열면 유저가 자기소개를 써도 채널이 안 열려 **첫 10분 골든타임에 "왜 안 열리지?" 혼란** 발생. 카피와 게이팅은 항상 한 방향.
> - 구현: Carl-bot은 "특정 채널에 글 작성 시 역할 부여"를 무료로 지원(오토모드/트리거). `#자기소개`에 글 → @정회원 자동 부여로 설정.
> - 백업책: Carl-bot 채널트리거 설정이 막히면, 임시로 `#규칙` ✅ 리액션롤로 등업하되 **그 경우 §3-1 규칙·§3-2 웰컴 카피를 "#규칙에서 ✅ 누르면 열려요"로 함께 교체**하고 자기소개는 '권장 첫 행동'으로 재프레이밍(정합 유지).

## 5) 세미나·당근모임 집객/리텐션 연결 전략

핵심 질문: **어떻게 데려오고(집객), 어떻게 남기나(리텐션).** 허영지표(입장수) 아닌 실제 참여·전환 관점.

### 5-1. 집객 — 당근/세미나 → 디스코드 유입 동선

| 접점 | 디스코드 안내 방식 | 주의 |
|---|---|---|
| 당근 번개/모임 **오프라인 현장** | 모임 끝에 "계속 얘기 나눌 단톡 대신 디스코드 있어요" QR/링크 | 당근 글 본문엔 링크 직접노출 지양(상업/외부유도 제재). **현장·댓글·개인메시지로** 안내 |
| 세미나 **신청 확정 메일/메시지** | "수강생 전용방 초대 링크" 포함 | 세미나 가치의 일부로 프레이밍 |
| 세미나 **당일 종료 시** | "오늘 자료·후속 질문은 디스코드 #수강생-전용에서" | 종료가 곧 커뮤니티 진입점 |
| build-in-public(유튜브쇼츠·스레드) | 영상/글 설명란에 서버 초대 링크 | 상단 깔때기. 모아 콘텐츠 보고 관심 생긴 사람 수용 |

**원칙(당근 정책):** 당근 모임 소개글엔 디스코드 링크·"강의" 직접 노출 금지([[2026-07-07_karrot_moim_pack]] 대원칙과 동일). 신뢰 쌓인 뒤 현장/개인 안내로 자연 전환.

### 5-2. 리텐션 — 남게 만드는 장치

1. **자랑방이 엔진.** 만든 것 올리면 반응 → 다시 옴. 형(운영)이 초기엔 **모든 자랑글에 반드시 반응**(리액션+한 줄). 초기 밀도는 운영이 만든다.
2. **세미나 후 48시간 후속.** 수강생-전용방에 세미나 자료+"이번 주 실습 미션" 1개 → 실습 인증 → 자연 리텐션. (강제 X, 가볍게)
3. **정기 리듬.** 주 1회 상설 `🔊 모각코` 고정 시간(예: 매주 특정 요일 저녁) → "오면 누군가 있다"는 예측가능성이 리텐션 핵심.
4. **@멘토(재능기부) 활용.** 당근 재능기부로 만난 열정멤버를 멘토로 등업 → 질문방 답변 → 커뮤니티 자생. (형 부담 분산)
5. **build-in-public 노출.** `#모아-빌드로그`에 모아가 실제 만드는 것 공개 → "여긴 진짜 돌아가는 걸 보여주는 곳" 신뢰 = 세미나 전환의 근거.

### 5-3. 측정 지표 (허영지표 배제)

| 보는 것 | 안 보는 것 |
|---|---|
| 첫주 리텐션(입장 7~14일 후 재방문률, 목표 30%+) | 총 입장수(허영) |
| 자기소개 작성률(=진짜 참여 의사) | 온라인 표시 인원 |
| 자랑방·질문방 주간 활성 글 수 | 서버 총 멤버 수 자체 |
| 디스코드→세미나 신청 전환 | - |

> 전환(세미나 결제)은 sales-head-jio 영역. 나는 "디스코드까지 데려오고 머물게" 책임. **디스코드 유입은 느는데 세미나 전환 0이면 즉시 CSO에 '병목=전환단계' 신호.**

## 6) 형 셋업 가이드 (클릭 순서 — 서버 생성은 형 계정만 가능)

> 서버 "생성"은 형 권한. 아래는 형이 클릭만 따라 하면 되는 순서. 각 단계 후 "됐어" 주시면 클로가 다음 안내/문구 제공.

**클로/형 역할 분담:** 형=서버생성·클릭 설정. 클로=모든 문구(규칙/웰컴/템플릿) 제공·봇 설정값 안내·검수.

### STEP 1. 서버 생성
1. 디스코드 좌측 `+` → "직접 만들기" → "친구와 함께" → 서버명 **"모아 바이브코딩"**(또는 형 선택), 아이콘 지정.

### STEP 2. 커뮤니티 기능 켜기 (온보딩 쓰려면 필수)
2. 서버설정 → **커뮤니티 사용 설정(Enable Community)** → 안내 따라 활성화. (규칙채널·기본 공지채널 자동 요구 → 아래서 만들 것)

### STEP 3. 카테고리·채널 생성 (§1 '지금 여는 채널' 9개만)
3. 카테고리 3개: `📢 시작하기` `💬 커뮤니티` `🎙 라이브`.
4. 각 카테고리에 §1 표대로 채널 생성. `#환영-공지`·`#규칙`은 **읽기전용**(권한: @everyone 메시지 보내기 끄기).

### STEP 4. 역할 만들기 (§2)
5. 서버설정>역할 → `정회원`(초록) `수강생`(파랑) `멘토`(보라) 생성. (@뉴비는 @everyone으로 대체 가능 — 굳이 안 만들어도 됨.)
6. **@everyone(뉴비) 권한 = 눈팅 허용을 기본값으로 고정: 커뮤니티 채널 "보기" ON · "메시지 보내기" OFF.** (정회원 등업 시 쓰기 개방.) → 이래야 뉴비도 온보딩 추천채널 `#자유수다`·`#질문방`을 볼 수 있어 첫인상에서 "빈 서버"로 안 느낌. ("보기"까지 끄면 뉴비에게 추천채널이 안 보여 골든타임 손실.)

### STEP 5. 봇 초대 (§4)
7. Carl-bot 사이트(carl.gg)에서 서버에 초대 → **봇 역할을 정회원/수강생/멘토보다 위로 드래그**(중요).
8. Carl-bot 대시보드: 웰컴메시지(§3-2), 자동모더레이션, **`#자기소개` 채널 글 작성 시 → @정회원 자동부여(A안 확정)** 설정.

### STEP 6. 온보딩 설정 (Discord 네이티브)
9. 서버설정>온보딩 → 규칙 동의 + 질문 1~2개("관심분야?" 정도, 3~5개 넘기지 말 것) + 채널추천에 `#자기소개`·`#자유수다`·`#질문방` 노출.

### STEP 7. 규칙·템플릿 게시
10. `#규칙`에 §3-1 붙여넣고 고정. `#자기소개`에 §3-3 템플릿 고정. `#환영-공지`에 웰컴 고정.

### STEP 8. 소프트 오픈
11. 형 + 테스트계정(**표시명 "모아 스튜디오" 브랜드로 — '클로' 등 내부 닉네임 노출 금지**) + 지인 2~3명 먼저 입장해 자기소개·자랑방 시드글 2~3개 심기(빈 서버 방지). → 그다음 당근/세미나 유입 개시.
