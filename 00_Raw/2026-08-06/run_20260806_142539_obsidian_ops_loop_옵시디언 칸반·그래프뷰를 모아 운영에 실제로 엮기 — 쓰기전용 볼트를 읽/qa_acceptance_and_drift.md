## 가장 현실적인 실패 시나리오 3개
1. **카드 이동 박제**: 카드가 7일 이상 움직이지 않으면, 데이터 동기화 문제로 인해 프론트매터 필드 값과 실제 상태가 불일치할 수 있다.
   - 영향: 작업 진행 상황의 정확성 저하
   - 감지: dataview 쿼리로 상태 변화를 확인
   - 대응: 카드 이동을 확인하고, 필요시 프론트매터 필드 값을 업데이트한다.

2. **프론트매터-칸반 불일치**: 카드의 프론트매터 필드 값과 실제 값이 일치하지 않으면, 데이터 정확성이 손상될 수 있다.
   - 영향: 작업 상태의 오류
   - 감지: dataview 쿼리를 사용하여 비교
   - 대응: 카드 내용을 검토하고, 프론트매터 필드 값을 수정한다.

3. **링크 결함**: 최근 7일 일지가 프로젝트 노트로의 링크를 보유하지 않으면, 정보 연결성이 저하될 수 있다.
   - 영향: 작업 내용의 접근 불편
   - 감지: dataview 쿼리를 사용하여 각 일지 파일을 분석
   - 대응: 관련 프로젝트 노트와 링크를 확인하고, 필요시 추가한다.
