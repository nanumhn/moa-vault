## 🎯 우리에 주는 시그널

1. **방향 검증**: 자율 OS + 픽셀 오피스 = 시장 인정 카테고리
2. **차별화 필수**: 카테고리 형성된 만큼 단순 추격하면 매몰
3. **우리만의 강점 (다른 프로젝트엔 없음):**
   - **회의 엔진** — 직원들이 실제 R1/R2/클로징 흐름으로 협업 (대부분 단순 단발 응답)
   - **HITL 형 결재 게이트** — 매 페이즈 종료 시
   - **Discord 비서 보고** — 멀티채널 인터페이스
   - **한국 직원 페르소나 + 도메인 특화** (음악·드라마·사주)
   - **moa-vault Skills 누적** — 진짜 self-growing (학습 노트 다음 회의에 system_prompt 주입)
   - **다중 페르소나 협업** (회의 산출물이 단일 에이전트 답변보다 깊음)

## 🛠️ harishkotra/agent-office에서 차용할 만한 패턴

- **에이전트 자율 채용** — 우리는 형이 직접 채용. 향후 직원이 "이런 역할이 필요해요" 제안하는 메커니즘 추가 가능
- **에이전트 간 작업 할당** — 현재 우리는 facilitator(도현)가 라운드별로 발언 분배. 횡적 task 위임 패턴은 미구현
- **persistent memory across sessions** — 우리는 Skills 폴더로 이미 구현 ✓
