# 영상 연출 디렉션 v2

## 전체 톤 한 줄 + 키워드 3
아련하고 기능적인 ‘기억의 오피스’. (Dusk Glow, 세이지 블루, 아카이브)

## 조명 hex 명세
| 구분 | 역할 및 특징 | Hex Code | 지침 |
| :--- | :--- | :--- | :--- |
| 메인 키 라이트 (Key Light) | **골든 오렌지 계열**. 황혼의 따뜻함과 '기억' 레이어 담당. 공간에 깊이와 아련함을 부여. | `#FFB86C` ~ `#E0A54F` | 낮은 각도에서 균일하게 확산되어야 함. (좌상단 광원 설정 필수) |
| 보조광 (Fill Light) | **세이지 블루 계열**. 기능성과 현재성을 담당하는 구조적 빛. 전면의 단조로움을 방지하고 대비 효과를 줌. | `#A7C2B1` | 간접 조명 및 모니터에서만 활용하며, 오브젝트 경계에 미세한 볼륨감 부여에 집중. |
| 그림자 (Shadow) | **뮤트 그레이-블루**. 절대적인 검정은 지양. 채도 낮은 푸른빛이 감도는 회색 톤으로 처리하여 공간의 깊이를 확보함. | `#8A93A5` | 광원 간의 경계선에 명확히 존재하며, 빛과 대비를 이루는 역할을 수행해야 함. |
