## 방별 명세

**1. 중앙 동선 (Central Flow Area)**
*   크기: 4×6 타일
*   사용 floor 타일: LimeZu floors.png, frame index #3 (오크 우드 계열)
*   벽 스타일: Walls.png, frame index #7 (낮은 목재 파티션 느낌)
*   배치할 가구 리스트:
    *   라운지 소파 (LimeZu Singles): 중앙 전면 배치, 2인용 + 3인용 조합.
    *   커피 테이블: 낮은 원형 우드 테이블 (중앙).
*   식물/소품: 대형 화분(몬스테라 등)을 동선 양 끝에 배치하여 공간의 경계를 부드럽게 분리.

**2. 집중 업무 구역 (Focused Work Zone)**
*   크기: 12×8 타일
*   사용 floor 타일: LimeZu floors.png, frame index #3 (오크 우드 계열)
*   벽 스타일: Walls.png, frame index #7 (낮은 목재 파티션). 파티션을 통해 개별 업무 공간 분리.
*   배치할 가구 리스트:
    *   책상 (데스크): 개인용 픽셀 워크스테이션 (4개 배치 예상)
    *   의자: 간결한 라인의 사무용 의자.
*   식물/소품: 각 데스크 주변에 작은 다육이 화분으로 '생명력' 부여.

**3. 비주얼 아카이브 월 (Mood Board Archive Wall)**
*   크기: 10×8 타일 (벽면 전체)
*   사용 floor 타일: N/A (전체 벽면 활용).
*   벽 스타일: Walls.png, frame index #9 (빈티지한 질감이 느껴지는 목재 패널 느낌으로 변경 요청).
*   배치할 가구 리스트:
    *   핀 보드/무드 보드 프레임: 주기적으로 스틸컷을 전시하는 구조물(10개 내외) 배치.
    *   빈티지 캐비닛: 작업 과정의 자료(스케치, 콘셉트 시트 등)를 정리할 수 있는 낮은 목재장 (좌측 끝).
*   식물/소품: 없음 (전시 공간 집중).

**4. 휴게/미팅실 (Rest/Meeting Room)**
*   크기: 10×8 타일
*   사용 floor 타일: LimeZu floors.png, frame index #5 (차분한 베이지 계열).
*   벽 스타일: Walls.png, frame index #7.
*   배치할 가구 리스트:
    *   대형 테이블: 6인용 미팅 테이블.
    *   의자: 편안하고 심리적 안정감을 주는 디자인의 의자.
*   식물/소품: 중앙에 작은 화분 배치하여 개방감 유지.
