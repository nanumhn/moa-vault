# 사주 서비스 정의

## 한 줄 정의
데이터 기반의 예측을 넘어, 사용자 스스로에게 '공감적 발견'과 위로를 제공하는 감성 콘텐츠 여정.

## 타깃 사용자 (1순위 / 2순위)
*   **1순위:** 자아 탐색기에 놓인 20대 후반~30대 초반 여성층. 막연한 불안감 속에서 '나만의 이야기'를 찾고자 하는 감성적 니즈가 강함.
*   **2순위:** 관계의 의미와 방향성에 대한 고민이 있는 남녀 사용자.

## 톤·무드 (엔터테인먼트/진지/위로 균형)
신비롭고 아련하지만, 결코 가볍거나 오락적이지 않게 '몽환적인 공감'을 주는 무드가 핵심이야. 진지함을 기반으로 위로를 얻는 느낌이 중요해.

## 핵심 차별점 3가지 (Co-Star/Sanctuary 대비)
1.  **발견의 과정(Process Focus):** 단순한 결과 예측 대신, '나만의 아련한 키워드' 같은 발견 과정을 시각화하여 공유하게 만드는 것.
2.  **공감형 콘텐츠:** 사주라는 거대한 데이터를 개인의 일상 무드 카드처럼 작고 소비하기 쉬운 형태로 변환하는 능력.
3.  **비주얼 스토리텔링:** 텍스트가 아닌, 마치 영화 속 장면 같은 시각적 티저와 배경음악으로 몰입도를 극대화할 것 같아.
