# 프론트엔드 명세

## Next.js 라우트 구조
- `(main)/` / 랜딩 페이지 (`/`)
- `(auth)/input` / 생년월일 및 시 입력 폼 (`/auth/input`)
- `(discovery)/flow/[page]` / 발견 과정 단계별 시퀀스 (페이지네이션) (`/discover/:step`)
- `(result)/report` / 최종 키워드 카드 및 공유 결과 페이지 (`/report`)
- `(pay)/gate` / 유료 구독 게이트 및 결제 Flow (`/pay/gate`)

## 핵심 화면 5개 와이어 설명
1. **랜딩 (Landing)** — 첫 1초 인상: 최소한의 정보 노출로 감성적 몰입감 부여. 초기 로드 시 LCP 최적화를 위해 이미지 대신 애니메이션 기반의 배경(CSS/SVG)을 사용하고, 'Enter' 버튼 클릭 유도를 통해 사용자 액션을 시작하게 설계.
2. **입력 (Input)** — 생년월일/시 입력 UX: Date Picker 컴포넌트와 Time Selector를 분리하여 직관성을 높임. 백엔드에서 받은 기본 데이터 유효성 검사(Validation)는 클라이언트 측에서 즉각 피드백 제공하며, 서버 액션으로 최종 데이터를 전송하는 구조로 설계.
3. **발견 시퀀스 (Discovery Sequence)** — '발견 과정' 시각화: 페이즈 1은 단순한 스크롤링을 넘어, 사용자의 입력값에 따라 배경의 색상/노이즈 패턴이 점진적으로 변화(MutationObserver 활용)하는 인터랙션을 중심으로 구현. 페이지 간 전환은 애니메이션으로 부드럽게 연결하여 '흐름' 자체를 콘텐츠로 만듦.
4. **리포트 (Report)** — 키워드 카드 + SNS 공유: 가장 핵심적인 결과 화면. 획득한 키워드는 아카이브된 디자인 시스템 컴포넌트를 활용해 시각화하며, 이 키워드를 기반으로 사용자 맞춤형 '요약 문구'를 생성하여 SNS 공유 기능을 제공함 (클라이언트 측 문자열 조합).
5. **구독 게이트 (Subscription Gate)** — $7.99 전환: 결제 로직의 복잡도를 분리하기 위해, 이 페이지는 최소한의 UX만 담당하고 실제 결제 처리는 백엔드에서 받은 세션 토큰 기반의 팝업/모달 컴포넌트를 통해 처리되도록 설계.

## i18n 구조
- `next-intl`을 사용하여 Locale 파일을 관리하며, 모든 사용자 인터페이스 텍스트(UX Copy)는 중앙화된 메시지 키로 분리합니다. 다국어 지원은 최소한의 문자열 번역에 집중하고, 전문 용어(예: Webhook, Rate Limiting)는 원문 표기를 병행하여 기술적 신뢰도를 유지합니다.

## 상태 관리
- **전역 상태 (Global State):** 사용자 정보 및 발견 과정에서 획득된 키워드 목록 등 영속성이 필요한 데이터는 Zustand를 사용하여 가볍고 예측 가능한 방식으로 관리합니다.
- **서버 상호작용:** 서버 액션(Server Action)을 주력으로 사용하며, 비동기 데이터 호출 및 상태 동기화에는 TanStack Query를 적용하여 캐싱 및 재시도 로직을 자동화하고 개발 생산성을 극대화합니다.

## 컴포넌트 라이브러리
- **기반:** shadcn/ui의 구조적 안정성과 커스터마이징 용이성을 활용하되, 핵심적인 '발견 시퀀스' 특수 효과(노이즈 필터, 색상 전환)는 자체 제작된 고성능 React 컴포넌트(`@components/mood-filter`)로 분리하여 재사용합니다.

## 성능 예산
- **LCP (Largest Contentful Paint):** 2.5초 이하 목표. 초기 로딩 시점에서 배경 이미지나 무거운 자바스크립트를 지연 로드(Lazy Load) 처리하고, Critical CSS를 인라인 삽입하여 첫 화면의 체감 속도를 최우선으로 확보합니다.
- **CLS (Cumulative Layout Shift):** 0.1 이하 목표. 모든 레이아웃 변경 요소는 반드시 명시적인 크기(`width`, `height`)와 애니메이션 트랜지션을 적용하여 페이지 전환 시 발생하는 깜빡임(Jank)을 근본적으로 제거합니다.
