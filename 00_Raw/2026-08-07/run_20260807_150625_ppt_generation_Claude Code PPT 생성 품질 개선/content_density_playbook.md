# PPT 콘텐츠 밀도 플레이북

## '풍성한 자료'의 정의
- 측정 가능한 정의: 각 슬라이드에 최소 2개 이상의 불릿 포인트, 출처 포함 데이터 및 시각적 요소를 삽입한다. 헤드라인이 슬라이드 전체 길이의 1/3 이내로 유지되며 본문은 한 줄당 60자 이하로 작성된다.

## 슬라이드 1장 구성 규칙
| 요소 | 기준 |
|---|---|
| 헤드라인 | 20자 이내 (헤드라인이 길어지면 전체 콘텐츠의 중심을 잃게 됨) |
| 본문 불릿 | 3개 이하, 한 줄당 60자 이하 (불필요한 정보가 텍스트에 포함되어 이해하기 어려워짐) |
| 근거/데이터 | 최소 2개 이상 (슬라이드가 추론이나 결론을 내리기 위해 충분한 근거를 제공해야 함) |
| 시각 요소 | 최소 1개 이상 (비주얼은 내용 이해를 돕고 보기에 흥미롭게 만듦) |

## 밋밋함을 막는 구조 규칙
1. 슬라이드 내에서는 데이터와 비주얼이 결합되어야 함.
2. 각 장마다 최소한의 콘텐츠만 포함하여, 전체 내용을 압축적으로 전달해야 함.
3. 본문 불릿은 명확하고 간결하게 작성되어야 하며, 불필요한 정보는 제거되어야 함.

## B2B 제안서 목차 템플릿
| # | 슬라이드 | 이 장이 답하는 질문 |
|---|---|---|
| 1 | 표지 | 대표 보고자료의 주제를 명확히 하기 위한 최초 인상은 무엇인가? |
|   | - 'ComfyUI + Flux' 로고와 함께 'PPT 콘텐츠 밀도 플레이북 제안서'로 표지 제목을 작성<br> - 푸른색(#00BFFF) 배경에 빨간색(#FF4500)으로 로고를 배치 |
| 2 | 문제점 제시 | 우리 솔루션으로 해결할 수 있는 문제는 무엇인가? |
|   | - '주요 문제점'을 불릿 포인트로 작성 (예: 헤드라인이 길어져 전체 내용의 중심을 잃음, 불필요한 정보가 텍스트에 포함되어 이해하기 어려움) <br> - 각 불릿은 한 줄당 60자 이하로 작성 |
|   | - 데이터와 비주얼이 결합된 그래프 또는 이미지 삽입 (예: 문제점 분석 그래프)<br> - 그래프는 시각적으로 강력한 효과를 내기 위해 최대한 간결하게 만들어야 함 |
| 3 | 현황 분석 | 현재 상황이 왜 중요한지 설명하라. |
|   | - '현황 분석'을 불릿 포인트로 작성 (예: 시장 점유율, 경쟁사 분석, 이전 솔루션의 효과 등) <br> - 각 불릿은 한 줄당 60자 이하로 작성 |
|   | - 데이터와 비주얼이 결합된 그래프 또는 이미지 삽입 (예: 시장 점유율 차트, 경쟁사 분석 차트)<br> - 차트는 자료를 명확하게 전달하기 위해 간단하고 직관적이어야 함 |
| 4 | 우리의 솔루션 | 어떻게 해결책을 제공하는지 구체적으로 설명하라. |
|   | - '우리의 솔루션'을 불릿 포인트로 작성 (예: 주요 기능, 특징, 사용자 사례 등) <br> - 각 불릿은 한 줄당 60자 이하로 작성 |
|   | - 데이터와 비주얼이 결합된 이미지 또는 그래프 삽입 (예: 솔루션 효과 비교 차트)<br> - 그래프는 시각적으로 강력한 대비를 내고, 텍스트에 대한 보완 역할을 해야 함 |

## 표지
- 표지는 프레젠테이션의 첫 인상을 결정하므로, 로고와 제목을 명확하게 작성해 전체 주제를 강조한다.

## 문제점 제시
- 문제점을 분석하여 고객의 필요성을 이해하고, 이를 해결하기 위한 우리의 솔루션을 추천할 수 있다.
- 그래프는 문제점을 시각적으로 보여주어 이해도를 높일 수 있다.

## 현황 분석
- 현재 상황을 분석하면, 우리 솔루션이 필요한 이유와 그 중요성을 설명할 수 있다.
- 차트는 시장 점유율과 경쟁사 분석을 명확하게 전달하여 고객의 이해도를 높일 수 있다.

## 우리의 솔루션
- 솔루션의 주요 기능과 특징을 구체적으로 설명하면, 고객이 우리 제품을 신뢰할 수 있게 한다.
- 그래프는 솔루션 효과를 비교하여 시각적으로 강력한 대비를 내며, 텍스트에 대한 보완 역할을 한다.
