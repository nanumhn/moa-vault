# PPT 콘텐츠 밀도 플레이북

작성: 이서아(콘텐츠본부장) · 보완: 정도현(COO, 검수 반려 4·5·6번 반영)

## '풍성한 자료'의 정의

풍성하다는 것은 글자가 많다는 뜻이 아니다. **슬라이드 한 장이 질문 하나에 답하고, 그 답을 뒷받침하는 근거와 시각 요소를 같이 갖고 있는 상태**를 말한다. 측정 기준은 아래 구성 규칙으로 대신한다. 글자를 늘려 채운 슬라이드는 밀도가 높은 것이 아니라 편집이 덜 된 것이다.

## 슬라이드 1장 구성 규칙

| 요소 | 기준 |
|---|---|
| 헤드라인 | 20자 이내. 그 장의 결론을 문장으로 쓴다 ("현황"이 아니라 "편당 4시간이 30분으로 준다") |
| 본문 불릿 | 3개 이하, 한 줄 60자 이하 |
| 근거/데이터 | 최소 1개. 수치를 쓰면 출처와 기준일을 반드시 같이 |
| 시각 요소 | 최소 1개 (이미지·차트·표 중 하나) |
| 답하는 질문 | 정확히 1개. 두 개를 답하려 하면 장을 나눈다 |

## 밋밋함을 막는 구조 규칙

1. **헤드라인을 명사가 아니라 문장으로 쓴다.** "비용 분석"은 아무 말도 하지 않는다. 결론을 헤드라인에 올리면 읽는 사람이 한 장에 3초만 써도 요지를 가져간다.
2. **한 장에 질문 하나.** 슬라이드가 두 가지를 설명하려 하면 둘 다 얕아진다. 나누면 장수는 늘어도 읽는 속도는 빨라진다.
3. **모든 장에 시각 요소를 하나 넣되, 장식용은 넣지 않는다.** 내용과 무관한 배경 이미지는 밀도를 올리지 못하고 신뢰만 떨어뜨린다.

## B2B 제안서 목차 템플릿

쇼츠 제작 자동화 납품 제안서 기준 12장이다.

| # | 슬라이드 | 이 장이 답하는 질문 |
|---|---|---|
| 1 | 표지 | 이건 누구를 위한 제안인가 |
| 2 | 문제 제기 | 지금 쇼츠를 사람이 만들면 무엇이 막히나 |
| 3 | 해결 개요 | 우리가 넘겨받는 범위와 고객이 손대는 범위의 경계는 |
| 4 | 타깃 이해 | 우리가 이 고객사의 상황을 정확히 알고 있나 |
| 5 | 경쟁력 비교 | 사람이 만드는 방식 대비 무엇이 줄어드나 |
| 6 | 파이프라인 | 실제로 어떤 순서로 만들어지나 |
| 7 | 일정 | 착수부터 첫 납품까지 얼마나 걸리나 |
| 8 | 사례 | 실제로 만든 결과물은 어떤가 |
| 9 | 결과 데이터 | 그 사례에서 나온 수치는 무엇인가 |
| 10 | 단가·계약 | 얼마이고 어떤 조건인가 |
| 11 | 리스크·보증 | 잘못되면 어떻게 되나 |
| 12 | 다음 단계 | 지금 무엇을 하면 되나 |

표지 사양은 고객사명과 "쇼츠 제작 자동화 납품 제안"을 상단에, 모아 스튜디오 로고를 하단에 배치한다. 브랜드 컬러는 디자인 시스템 문서의 팔레트(Primary `#3498db`, Accent `#f1c40f`, 배경 `#ffffff`, 본문 `#2c3e50`)를 따른다. 내부 도구명이나 내부 문서 제목은 고객용 산출물에 절대 넣지 않는다.

## 분량 권장안

| 용도 | 슬라이드 수 |
|---|---|
| B2B 제안서 | 12장 (10~15장 범위) |
| 대표 보고자료 | 5~8장 |
| 투자·파트너 소개 | 12~20장 |

제안서가 20장을 넘으면 읽히지 않는다. 넘칠 것 같으면 본문을 줄이는 게 아니라 부록으로 뺀다.

## 장황해질 때 자르는 기준

**그 문장을 지웠을 때 상대의 결정이 달라지는가.** 달라지지 않으면 뺀다.

구체적으로는 이 순서로 자른다.
1. 우리 회사 소개 중 수주와 무관한 연혁·수상 이력
2. 기술 내부 구조 설명 — 고객은 어떻게 만드는지가 아니라 무엇을 받는지가 궁금하다
3. 같은 말을 다르게 반복한 문장
4. "~할 수 있습니다" 류의 일반론 — 숫자로 바꾸거나 버린다

## 흔한 실패 패턴

- **템플릿의 예시 문구가 그대로 나감** — 고객사명 자리에 다른 회사 이름이 남아 있는 사고가 가장 잦고 가장 치명적이다. 발송 전 치환 항목을 전수 확인한다.
- **근거 없는 수치로 설득하려 함** — "3배 향상" 같은 표현은 출처가 없으면 쓰지 않는다. 회사 규칙이고 품질 게이트에서 차단된다.
- **모든 장에 불릿 7개씩** — 밀도가 아니라 미편집이다. 읽는 사람은 한 장에서 한 가지만 기억한다.
- **사례를 앞으로 당김** — 증거가 자랑으로 바뀐다. 사례는 문제·해결 다음에 온다.
