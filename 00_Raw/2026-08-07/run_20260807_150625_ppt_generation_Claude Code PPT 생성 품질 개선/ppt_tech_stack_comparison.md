# PPT 생성 기술 스택 비교

## 후보 비교표
| 방식          | 디자인 자유도   | 편집 가능한 .pptx | 구현 난이도  | Claude Code 적합도 | 비고           |
|---------------|-----------------|--------------------|--------------|--------------------|---------------|
| python-pptx    | 높음            | 가능              | 중간         | 좋음               | 정교한 비주얼 제작 가능, 코드량 많음     |
| pptxgenjs      | 중간            | 가능              | 낮은        | 좋음               | Node.js 기반, 차트 API 풍부             |
| Marp / Reveal.js | 높음          | 불가능             | 낮은        | 나쁨               | 마크다운 및 HTML+CSS 사용, .pptx 아님   |
| HTML렌더→이미지→pptx | 중간      | 가능              | 낮은        | 나쁨               | 디자인 자유도 높지만 슬라이드 안 텍스트 수정 불가 |

## 권고 1안
- 선택: python-pptx + HTML/CSS 렌더링
- 이유 3가지:
  1. 정교한 비주얼 제작이 필요할 때 python-pptx를 사용하여 원하는 결과물을 얻을 수 있다.
  2. 편집 가능한 .pptx가 최종 요구사항인 점을 고려하면 python-pptx가 가장 적합하다.
  3. HTML/CSS 렌더링 기능을 추가하여 디자인 자유도를 유지하면서도 필요한 텍스트와 이미지를 쉽게 수정할 수 있다.

## 대안 (1안이 막힐 때)
- pptxgenjs + Marp / Reveal.js
- 이유 3가지:
  1. python-pptx가 제한적인 경우, 차트 API를 활용하기 위해 pptxgenjs를 사용하는 것이 유용하다.
  2. Marp / Reveal.js는 마크다운과 HTML+CSS로 슬라이드를 생성할 수 있으므로 디자인 자유도를 높일 수 있다.
  3. 이 방법은 python-pptx와의 호환성을 유지하면서도 다양한 기능을 제공한다.

## 생성 파이프라인 단계
1. 입력 — 주제/자료는 마크다운 형식으로 입력받으며, 필요한 텍스트와 이미지 정보를 포함해야 한다.
2. 원고 생성 — 마크다운 파일을 분석하여 슬라이드의 내용과 순서를 결정한다.
3. 레이아웃 배치 — 각 슬라이드에 맞는 레이아웃을 설정하고, 필요한 텍스트와 이미지를 배치한다.
4. 비주얼 삽입 — 정교한 비주얼은 python-pptx로 생성하고, 디자인 자유도를 높이는 부분은 HTML/CSS 렌더링을 사용하여 추가한다.
5. .pptx 출력 — 최종적으로 편집 가능한 .pptx 파일을 생성하여 저장한다.

## Claude Code 실행 명령 예시


## 예상 리스크 3개와 대응
1. 정교한 비주얼 제작 시 시간이 오래 걸릴 수 있다 → python-pptx를 사용하여 필요한 만큼의 세부적인 설정을 적용하며, 필요한 경우 별도로 작업해 시간을 단축한다.
2. HTML/CSS 렌더링 부분에서 텍스트 수정 불가 문제가 발생할 수 있다 → 슬라이드 안의 텍스트는 가능한 한 python-pptx를 사용하여 직접 추가하고, 필요에 따라 HTML/CSS 렌더링으로 조정한다.
3. 차트 삽입 시 차트 API 활용이 제한적일 수 있다 → pptxgenjs를 추가적으로 사용하여 차트를 생성하고, 필요한 경우 python-pptx와 함께 사용하여 최종 슬라이드를 완성한다.
