# 데이터 시각화 규격

작성: 박나래(인사이트 분석가) · 보완: 정도현(COO, 검수 반려 3·6번 반영)

## 차트 유형별 사용 기준

| 차트 | 언제 쓰나 | 쓰면 안 될 때 |
|---|---|---|
| 막대 | 카테고리 간 크기를 비교할 때 (예: 채널별 납품 건수) | 항목이 12개를 넘어 축이 뭉갤 때 — 표로 대체 |
| 꺾은선 | 시간에 따른 추세를 보여줄 때 (예: 월별 발행 편수 추이) | 시점이 3개 이하일 때 — 추세로 읽히지 않으므로 막대로 |
| 파이 | 전체를 100%로 놓고 구성비를 보여줄 때 (예: 매출 구성) | 항목이 5개를 넘거나, 두 시점을 비교해야 할 때 — 비교는 막대가 정확하다 |
| 누적 막대 | 구성비와 총량을 동시에 보여줄 때 | 각 구성요소의 증감을 정확히 읽혀야 할 때 — 밑변이 흔들려 오독된다 |

## 데이터 입력 형식

```json
{
  "title": "채널별 납품 건수",
  "chartType": "bar",
  "labels": ["A사", "B사", "C사"],
  "series": [{ "name": "2026 상반기", "values": [12, 8, 5] }],
  "source": "사내 납품 원장 (2026-06-30 기준)",
  "asOf": "2026-06-30"
}
```

`source`와 `asOf`는 선택 필드가 아니다. 둘 중 하나라도 비면 차트를 만들지 않는다.

## 수치·출처 표기 규칙

1. 모든 차트 아래에 출처와 기준일을 캡션으로 표기한다. 형식: `출처: {source} · 기준일: {asOf}`.
2. 기준일은 **데이터를 수집한 날**이다. 파일을 만든 날이 아니다.
3. 외부 자료를 인용하면 출처에 확인 가능한 경로(URL 또는 문서명)를 남긴다. "내부 자료"만 적는 것은 출처가 아니다.

## 출처 없는 수치 차단 장치

- **검사 항목**: 차트 원본 JSON의 `source`·`asOf`가 비어 있는지 확인한다.
- **위반 시 조치**: **P0 발행 차단.** 차트를 생성하지 않고 에러로 중단한다.
- 라벨을 붙여 통과시키지 않는다. `(예시)`·`(불명)` 같은 표기로 넘기는 경로는 두지 않는다. 회사 규칙은 "출처 없는 수치는 지어내지 않는다"이며 이는 차단 규칙이다. 라벨링은 규칙을 지킨 것이 아니라 우회한 것이고, 그렇게 나간 슬라이드는 고객에게 근거 있는 숫자처럼 읽힌다.
- 템플릿용 더미 데이터는 발행 대상 파일에 들어가지 않도록 분리한다. 고객 제출본에 들어가는 순간 위 규칙이 그대로 적용된다.

## 데이터가 없거나 불충분할 때

- **대체 시각화**: 표 또는 문장으로 사실만 적는다. 수치를 만들어 채우지 않는다.
- **절대 하면 안 되는 것**: 빈 차트를 넣거나, 추정치를 실측치처럼 표기하는 것. 추정이 필요하면 "추정"임과 산출 근거를 같이 적는다.
- 데이터가 없다는 사실 자체를 슬라이드에 쓰는 편이 낫다. 근거 없는 숫자보다 정직한 공백이 제안서의 신뢰를 지킨다.

## 차트 시각 규격

| 항목 | 기준 |
|---|---|
| 색상 수 | 4개 이내. 브랜드 팔레트(Primary #3498db, Accent #f1c40f)를 기준으로 쓰고, 강조할 계열 하나만 Accent |
| 범례 | 계열이 2개 이상일 때만 표시하고 차트 위쪽에 둔다. 계열이 1개면 제목이 곧 범례이므로 생략 |
| 축 레이블 | 단위를 반드시 포함한다 (예: `건`, `만원`, `%`) |
| 데이터 라벨 | 막대·파이는 표시, 꺾은선은 시점이 6개를 넘으면 생략(겹쳐서 못 읽는다) |
| 숫자 표기 | 천 단위 구분 쉼표를 넣는다 (예: `1,250`). 소수점은 필요할 때만 첫째 자리까지 |
| 제목 | 15자 이내로 무엇을 보여주는 차트인지 적는다 (예: `채널별 납품 건수`) |
| 크기 | 본문 영역 기준 가로 8in 이내. 렌더 이미지로 얹을 경우 1920×1080px @96dpi로 생성 후 축소 배치 |
