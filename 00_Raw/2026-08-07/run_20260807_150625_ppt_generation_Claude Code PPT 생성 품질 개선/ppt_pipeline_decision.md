# PPT 생성 파이프라인 — 회의 결정문

## 결론 한 문단
이번 회의에서는 PPT 생성에 필요한 기술 스택, 디자인 규격, 비주얼 에셋 조달처, 데이터·차트 표기 방식 등 여러 요소를 결정하였다. 개발본부는 이를 바탕으로 품질 게이트 기준을 충족하는 PPT 생성 및 제작 과정을 구체화하고 구현할 예정이다.

## 확정 사항
| # | 항목 | 결정 | 근거 |
|---|---|---|---|
| 1 | 기술 스택 | python-pptx와 HTML 렌더→ 이미지→ pptx를 사용한다. | 디자인 자유도, 편집 가능성, 구현 난이도 등을 고려한 선택결정 |
| 2 | 디자인 규격 | 색상 팔레트는 #3498db(# Primary), #f1c40f(# Accent), #ffffff(# 배경), #2c3e50(# 본문 텍스트)을 사용하며, 타이포그래피는 Montserrat Bold, Montserrat SemiBold, Roboto Regular, Roboto Light를 기준으로 한다. | 디자인 시스템의 구체적 제시 |
| 3 | 비주얼 에셋 | 배경/무드 이미지는 Unsplash, Pexels에서, 아이콘은 Icons8, Flaticon에서 조달하며, 한글 텍스트가 포함된 그래픽은 HTML+CSS 렌더링을 사용한다. | 비주얼 자산 파이프라인의 구체적 조달처 결정 |
| 4 | 데이터·차트 | 차트 유형과 출처 표기 방식, 수치와 출처를 JSON으로 입력하며, 출처 없는 수치는 지어내지 않는다. | 데이터 시각화 규격 문서에 따르며, 출처와 기준일이 함께 표시된다. |
| 5 | 품질 게이트 | AC1, AC2, AC3, AC4, AC5를 충족해야 하며, P0는 발행 차단 항목, P1은 경고 후 자동 보정 항목으로 구분한다. | 품질 게이트 기준 문서에 따르며, 각 항목의 우선순위와 측정 방법을 명시 |
| 6 | 1순위 활용처 | 외주·B2B 제안서를 1순위로 선정하여 PPT를 생성한다. | 활용처 우선순위 문서에서 외주·B2B 제안서의 특성과 요구 사항을 고려한 결정 |

## 파이프라인 단계
1. 디자인 규격에 따라 슬라이드 레이아웃 그리드를 정의하고, 색상 팔레트와 타이포그래피를 적용한다.
2. python-pptx와 HTML 렌더→ 이미지→ pptx 기술 스택을 사용하여 각 슬라이드에 텍스트, 차트, 비주얼 요소를 삽입한다.
3. Unsplash, Pexels에서 배경/무드 이미지를, Icons8, Flaticon에서 아이콘을 조달하고, HTML+CSS 렌더링으로 한글 텍스트가 포함된 그래픽을 생성한다.
4. 데이터와 차트는 JSON 형식으로 입력하여 출처를 표기하며, 출처 없는 수치는 지어내지 않는다.
5. 각 슬라이드의 콘텐츠가 AC1부터 AC5까지 기준에 맞는지 검토하고, 문제가 있으면 수정한다.
