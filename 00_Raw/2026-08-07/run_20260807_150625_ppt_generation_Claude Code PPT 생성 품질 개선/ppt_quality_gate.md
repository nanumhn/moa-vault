# PPT 품질 게이트

## 인수 기준 (AC)
| ID | 기준 | 측정 방법 | 우선순위 |
|---|---|---|---|
| AC1 | .pptx 파일 형식 확인 | pptx 확장자와 파일 구조 검사 | P0 |
| AC2 | 디바이스 독립성 확인 | 다양한 뷰어에서 정상 작동 여부 확인 | P0 |
| AC3 | 슬라이드 규격 확인 | 16:9 비율 체크 (최소 480x270 픽셀) | P1 |
| AC4 | 차트 출처 표기 확인 | 모든 차트에 출처와 기준일 표시 확인 | P1 |
| AC5 | 한글 텍스트 렌더링 확인 | HTML/CSS를 사용한 한글 텍스트 존재 여부 확인 | P2 |

## P0 — 발행 차단 항목
- [ ] .pptx 파일이 아님 (예: .docx, .pdf) - ComfyUI는 .pptx 형식을 사용하므로 이러한 파일들은 불리기 때문에 반려.
- [ ] 16:9 비율 미달 (예: 480x320 픽셀) - 16:9 비율은 슬라이드의 최소 크기를 설정해 품질을 보증한다.

## P1 — 경고 후 자동 보정
- [ ] 출처가 없는 차트 존재 (수정 요청 필요) - 모든 차트는 출처와 기준일이 포함되어야 하며, 이를 확인하고 없으면 수정해야 한다.
- [ ] 기준일 없거나 틀린 차트 존재 (수정 요청 필요) - 차트의 기준일은 정확하게 설정되어 있어야 함. 이를 검사하고 필요한 경우 수정해야 한다.

## 검사 대상
- 입력 파일 형식: .pptx와 슬라이드 원고
- 검사 스크립트가 읽어야 할 것: pptx 파일, 슬라이드 원고 파일

## 위반 시 조치
| 위반 | 조치 |
|---|---|
| .pptx 파일이 아님 | 반려 (예: .docx 또는 .pdf 파일은 불리기 때문에 반려) - ComfyUI는 이미지 생성 도구이며, 텍스트나 원고를 만들지 않으므로 .pptx 형식을 사용해야 한다.
| 16:9 비율 미달 | 자동 보정 (비율 조정, 예: 480x320 픽셀을 480x270 픽셀로 조정) - 16:9 비율은 슬라이드의 최소 크기를 설정해 품질을 보증한다.
| 출처가 없는 차트 존재 | 경고 (수정 요청), 모든 차트의 출처와 기준일이 정확하게 표기되어야 함 - 이는 데이터의 신뢰성을 높이고, 정보 제공을 명확하게 한다.
| 기준일 없거나 틀린 차트 존재 | 경고 (수정 요청), 차트의 기준일이 올바르게 설정되어 있어야 함 - 이를 통해 차트의 정확성과 신뢰성을 확보한다.

## 가장 흔할 실패 3가지
1. .pptx 파일 형식 미달 — .pptx 파일 확장자와 구조를 확인해 대상 슬라이드의 뷰어에서 정상 작동 여부를 검사한다 (예: .docx 또는 .pdf 파일은 불리기 때문에 반려) - ComfyUI는 이미지 생성 도구이며, 텍스트나 원고를 만들지 않으므로 .pptx 형식을 사용해야 한다.
2. 16:9 비율 미달 — 16:9 비율을 확인하고, 필요에 따라 슬라이드 크기를 조정하여 비율을 만족시킨다 (예: 480x320 픽셀을 480x270 픽셀로 조정) - 이는 슬라이드의 품질과 시각적 경험을 보장한다.
3. 출처가 없는 차트 존재 — 모든 차트에서 출처와 기준일이 정확하게 표기되었는지 검사하여 필요한 수정을 요구한다 (수정 요청) - 이는 데이터의 신뢰성을 높이고, 정보 제공을 명확하게 한다.

이러한 점들을 고려하여 PPT 품질 게이트를 검사하면, 품질 보증과 정확성을 확보할 수 있다.
