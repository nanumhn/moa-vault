# 슬라이드 디자인 시스템

작성: 오세린(비주얼 디자이너) · 보완: 정도현(COO, 검수 반려 6번 + 참고 지적 반영)

## 밋밋해 보이는 원인 진단

- 텍스트만 있고 시각 요소가 없다. 슬라이드가 문서처럼 읽힌다.
- 컬러와 글자 크기가 장마다 달라 전체가 산만하다. 화려함은 장식이 아니라 일관성에서 나온다.
- 여백과 정렬 기준이 없어 요소가 아무 데나 놓인다. 그리드가 없으면 무엇을 넣어도 정돈돼 보이지 않는다.

## 컬러 팔레트

| 역할 | hex | 사용처 |
|---|---|---|
| Primary | `#3498db` | 슬라이드 제목, 섹션 구분 배경, 차트 기본 계열 |
| Accent | `#f1c40f` | 강조할 수치 하나, 차트에서 부각할 계열 하나 |
| 배경 | `#ffffff` | 본문 슬라이드 배경 |
| 본문 텍스트 | `#2c3e50` | 본문, 캡션, 출처 |

한 장에 Accent는 한 군데만 쓴다. 두 군데를 강조하면 강조가 사라진다.

## 타이포 위계

| 요소 | 폰트 | 크기(pt) | 굵기 |
|---|---|---|---|
| 슬라이드 제목 | Montserrat | 40 | Bold |
| 소제목 | Montserrat | 24 | SemiBold |
| 본문 | Roboto | 16 | Regular |
| 캡션·출처 | Roboto | 10 | Light |

## 레이아웃 그리드

- 슬라이드 규격: 16:9 — 가로 13.333in × 세로 7.5in
- 여백: 상 0.6in / 하 0.5in / 좌우 0.8in
- 컬럼 그리드: 12열, 열 간격 0.15in

> 여백은 처음에 상하 2in으로 잡았다가 고쳤다. 7.5in 높이에서 상하 2in씩이면 세로의 53%가 여백이 되어 40pt 제목을 넣는 순간 본문 자리가 남지 않는다.

## 레이아웃 유형 5종

### 1. 표지
- 구성: 고객사명 + 제안 제목(상단), 모아 스튜디오 로고와 날짜(하단), 배경 이미지 전면
- 사용 상황: 첫 장. HTML/CSS 렌더 이미지로 처리한다

### 2. 섹션 구분
- 구성: Primary 배경 위에 섹션 번호와 제목만
- 사용 상황: 목차의 큰 단락이 바뀔 때. HTML/CSS 렌더 이미지로 처리한다

### 3. 본문 + 이미지
- 구성: 좌 7열 텍스트(헤드라인 + 불릿 3개 이하), 우 5열 이미지
- 사용 상황: 대부분의 설명 슬라이드. python-pptx 네이티브 개체로 만든다

### 4. 데이터 차트
- 구성: 헤드라인(결론 문장) + 차트 + 출처 캡션
- 사용 상황: 수치를 보여줄 때. 차트는 python-pptx 네이티브 차트로 넣어 편집 가능하게 유지한다

### 5. 마무리 / CTA
- 구성: 요약 한 문장 + 다음 단계 2~3개 + 연락처
- 사용 상황: 마지막 장

## 화려함을 만드는 장치 (코드로 재현 가능한 것만)

1. **전면 배경 이미지 + 어두운 오버레이 + 흰 텍스트** — 표지와 섹션 구분에 쓴다. 오버레이 불투명도 45%면 어떤 이미지 위에서도 글자가 읽힌다.
2. **좌측 컬러 바** — 본문 슬라이드 왼쪽에 Primary 색 세로 바(폭 0.15in)를 넣으면 장이 통일돼 보인다. 도형 하나로 끝나는 값싼 장치다.
3. **수치 한 개만 크게** — 강조할 숫자를 72pt Accent로 키우고 나머지를 본문 크기로 둔다. 대비가 화면을 만든다.

## 하지 말아야 할 것

- 한 장에 폰트 3종 이상, 컬러 4색 이상 쓰지 않는다.
- 출처 없는 데이터·차트를 넣지 않는다. 품질 게이트에서 차단된다.
- 내부 도구명·내부 문서 제목을 고객용 슬라이드에 넣지 않는다.

## 이미지 처리 기준

- 한글 텍스트가 들어가는 그래픽은 **HTML/CSS 렌더**로 만든다. 로컬 이미지 생성 모델(ComfyUI + Flux)은 한글 글자를 제대로 렌더하지 못하므로 글자 없는 배경·무드 이미지에만 쓴다.
- 렌더 이미지는 1920×1080px @96dpi로 생성해 슬라이드 전면에 배치한다.
- 이미지 1장은 200KB 이하를 권장하고 500KB를 넘기지 않는다. `.pptx` 파일 전체는 8MB 한도로 운영하며, 초과하면 이미지를 재압축한다. (두 값은 층위가 다르다 — 앞은 이미지 1장, 뒤는 파일 전체)
