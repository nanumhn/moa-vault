# 슬라이드 디자인 시스템

## 밋밋해 보이는 원인 진단
- 텍스트 위주로 구성되어 디테일한 비주얼 요소가 부족하다.
- 컬러 팔레트와 타이포그래피가 일관성 없이 사용된다.
- 레이아웃과 구조가 명확하지 않아 시각적 흐름을 저해한다.

## 컬러 팔레트
| 역할 | hex | 사용처 |
|---|---|---|
| Primary | #3498db | 제목, 주요 버튼 (10개) |
| Accent | #f1c40f | 강조, 캡션 (20개) |
| 배경 | #ffffff | 표지, 본문 배경 (50개) |
| 본문 텍스트 | #2c3e50 | 본문, 출처 (300자 이상) |

## 타이포 위계
| 요소 | 폰트 | 크기(pt) | 굵기 |
|---|---|---|---|
| 슬라이드 제목 | Montserrat Bold | 48 | Bold |
| 소제목 | Montserrat SemiBold | 32 | Regular |
| 본문 | Roboto Regular | 16 | Regular |
| 캡션·출처 | Roboto Light | 10 | Regular |

## 레이아웃 그리드
- 슬라이드 규격: 16:9 (가로 13.33in × 세로 7.5in)
- 여백 규칙: 상하 2in, 좌우 1in
- 컬럼 그리드: 4열

### 왜 이렇게 설정했는지
레이아웃은 프레젠테이션의 흐름을 매끄럽게 만들고, 중요한 정보를 쉽게 인지할 수 있도록 설계되었습니다. 여백 규칙과 컬럼 그리드는 시각적 조화와 안정감을 제공합니다.

## 레이아웃 유형 5종
### 1. 표지
- 구성: 제목, 미니타입, 출처
- 사용 상황: 프레젠테이션 시작 페이지

### 2. 섹션 구분
- 구성: 소제목, 간단한 이미지 또는 아이콘
- 사용 상황: 각 부분의 구분

### 3. 본문 + 이미지
- 구성: 본문 텍스트와 관련된 이미지
- 사용 상황: 내용 설명 페이지

### 4. 데이터 차트
- 구성: 차트, 출처 정보
- 사용 상황: 통계적인 데이터 표시

### 5. 마무리 / CTA
- 구성: 요약 문구, CTAs, 감사 인사
- 사용 상황: 프레젠테이션 종료 페이지

## 화려함을 만드는 장치 (코드로 재현 가능한 것만)
1. 이미지 슬라이싱과 겹쳐진 투명도 효과를 통해 디테일한 비주얼을 추가한다.
2. 타이포그래피의 크기와 굵기를 조절하여 시각적 흐름을 강조한다.
3. 배경에 그라디언트 효과를 적용하고, 필요한 부분에 깊은 색상으로 강조한다.

### 왜 이렇게 설정했는지
이러한 장치들은 슬라이드의 관심을 끌고 시각적 흐름을 유도하기 위해 사용됩니다. 이미지와 타이포그래피를 조절하면 프레젠테이션 전체에 활력과 전문성을 추가합니다.

## 하지 말아야 할 것
- 클리셰된 디자인 패턴을 사용하지 않는다.
- 출처 없는 데이터나 차트를 삽입하지 않는다.

### 왜 이렇게 설정했는지
클리셰된 디자인은 프레젠테이션의 독특성을 잃게 하므로 피해야 합니다. 또한, 출처 없는 정보는 신뢰성 문제를 일으키므로 사용을 금합니다.

## 슬라이드 품질 제고
- 이미지 렌더링: ComfyUI는 한글 글자를 지원하지 않으므로, HTML/CSS 렌더로 만든 그래픽만으로 한글 텍스트가 들어가는 부분을 처리한다.
- 이미지 크기: 임베드된 이미지는 최대 8MB까지이며, 필요에 따라 다시 압축하여 적절한 크기로 유지한다.
- 프레젠테이션 전략: 각 슬라이드는 명확하고 간결하게 구성되며, 중요한 내용만 포함된다. 이는 이해도를 높이고 관객의 집중력을 유지하는데 도움을 줌.

### 왜 이렇게 설정했는지
ComfyUI의 한글 글자 제한은 슬라이드에 HTML/CSS 그래픽을 사용하도록 강제합니다. 이미지를 적절하게 크기 조정하여 전송 시간과 메모리 부담을 줄이고, 프레젠테이션의 효율성을 높입니다.

## 색상 선택
- Primary: #3498db는 공감, 신뢰를 주며, 슬라이드에서 중요한 요소를 강조하기에 적합하다.
- Accent: #f1c40f은 화사하고 활기찬 느낌을 주어 눈길을 끌고, 캡션과 출처 정보의 역할을 잘 수행한다.
- 배경: #ffffff는 깨끗한 시각적 흐름을 제공하며, 본문과 출처를 명확하게 구분하기에 이상적이다.
- 본문 텍스트: #2c3e50는 높은 대조도를 유지하면서 내용의 읽기 용이성을 보장한다.

### 왜 이렇게 설정했는지
색상 선택은 각 요소가 시각적으로 균형을 이루고, 중요한 정보가 눈에 띄도록 설계되었습니다. 색상은 사용자의 주시를 유도하고, 프레젠테이션의 전반적인 분위기를 조절하는데 효과적입니다.

## 타이포그래피 선택
- Montserrat는 모던하고 깔끔한 느낌을 주며, 다른 글꼴과의 일관성을 유지하기에 적합하다.
- Roboto는 이전 버전에서 사용되었지만, Montserrat와 더 잘 어울리고, 다양한 슬라이드 유형에서 일관된 시각적 흐름을 제공한다.

### 왜 이렇게 설정했는지
타이포그래피 선택은 전체 프레젠테이션의 일관성과 전문성을 보장합니다. Montserrat와 Roboto의 조합은 각 슬라이드가 유기적으로 연결되도록 도와줍니다.

## 이미지 활용
- 이미지는 가능한 한 최적화되어야 하며, 필요에 따라 투명도 효과를 적용하여 디테일을 강조한다.
- 이미지 크기는 16:9 비율에 맞추어 조정되며, 여백 규칙은 이미지와 텍스트 간의 균형을 유지하는데 도움을 줌.

### 왜 이렇게 설정했는지
이미지는 프레젠테이션의 시각적 흥미를 높이고, 정보 전달에 효과적입니다. 이미지를 최적으로 조정하면 관객의 관심을 끄는데 중요합니다.

## 예시 슬라이드 구성
### 표지
- 제목: "프레젠테이션 제목"
- 미니타입: "작성자 이름, 날짜"
- 출처: "(예시) 출처 정보"

### 섹션 구분
- 소제목: "섹션 1의 주제"
- 간단한 이미지: "섬네일 아이콘 (예: 그래픽 라이브러리에서 가져온 것으로, 실제 사용 예시 포함)"

### 본문 + 이미지
- 본문 텍스트: "프레젠테이션 내용 (100자)"
- 관련 이미지: "그래픽 라이브러리에서 가져온 이미지 (예: 데이터 차트, 플로어 평면도 등)"

### 데이터 차트
- 차트: "통계적인 데이터 시각화 (예: 막대 그래프, 원형 차트)"
- 출처 정보: "(예시) 출처 정보"

### 마무리 / CTA
- 요약 문구: "본문 요약 (100자)"
- CTAs: "추가 자료 확인하기, 질문 하러 가기"
- 감사 인사: "감사의 말씀"

### 왜 이렇게 설정했는지
이 예시 슬라이드 구성은 각 유형의 슬라이드를 명확하게 구분하고, 중요한 정보를 효과적으로 전달하기 위해 설계되었습니다. 각 슬라이드가 독립적이면서도 전체 프레젠테이션과 일관되도록 만들어집니다.

## 결론
위의 디자인 시스템은 ComfyUI와 Flux의 한글 글자 제한을 고려하여, 일관성 있고 전문적인 슬라이드를 생성하기 위해 설계되었습니다. 이를 통해 프레젠테이션의 품질과 효과성을 높일 수 있습니다.

### 왜 이렇게 설정했는지
결론적으로, 이 시스템은 ComfyUI와 Flux의 제한을 극복하고, 프레젠테이션이 전문적이고 일관된 모습으로 제작될 수 있도록 설계되었습니다.
