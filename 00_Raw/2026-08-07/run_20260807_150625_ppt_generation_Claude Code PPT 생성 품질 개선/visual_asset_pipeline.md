# 슬라이드 비주얼 에셋 파이프라인

작성: 강시우(영상제작본부장) · 보완: 정도현(COO, 검수 반려 3·6번 + 참고 지적 반영)

## 에셋 유형별 조달처

| 유형 | 조달 방법 | 비용 | 비고 |
|---|---|---|---|
| 배경/무드 이미지 | 로컬 ComfyUI + Flux 생성 (1순위), Unsplash·Pexels (2순위) | 무료 | 글자 없는 이미지만. 로컬 생성이 우선이고 톤이 안 맞을 때 스톡으로 |
| 아이콘 | Icons8, Flaticon | 무료 등급 우선 | 유료 등급 전환은 대표 결재 대기 항목 |
| 한글 텍스트가 들어간 그래픽 | HTML/CSS 렌더 | 무료 | 표지·섹션 구분·인포그래픽이 여기 해당 |
| 인물/사진 | 유료 스톡 (Shutterstock 등) | 유료 | **대표 결재 대기.** 승인 전까지는 인물 사진을 쓰지 않는 구성으로 만든다 |

## 로컬 ComfyUI + Flux 사용 범위

- **쓸 곳**: 글자가 없는 배경·무드·일러스트 이미지. 로컬에서 무료로 양산할 수 있어 표지 배경 후보를 여러 장 뽑기 좋다.
- **쓰면 안 되는 곳**: 한글 텍스트가 들어가는 그래픽. Flux는 한글 글자를 제대로 렌더하지 못해 글자가 뭉개지거나 없는 문자로 나온다.
- **대안**: 한글이 필요한 그래픽은 전부 HTML/CSS 렌더로 만든다. 이쪽은 폰트를 그대로 쓰므로 글자가 정확하다.

## 실행 순서

1. **프롬프트 추출** — 슬라이드 원고에서 그 장의 주제어와 무드를 뽑아 영문 이미지 프롬프트로 변환한다. 프롬프트에 글자를 넣지 않는다.
2. **생성** — ComfyUI에서 장당 4장씩 뽑는다. 1920×1080px로 생성한다.
3. **후보 선별** — 주제 적합성과 텍스트 가독성(오버레이를 얹었을 때 글자가 읽히는지)으로 고른다. 배경이 복잡하면 표지에서 제목이 묻힌다.
4. **삽입** — 선택한 이미지를 슬라이드 전면에 배치하고 어두운 오버레이(불투명도 45%)를 얹는다.

## 브랜드 톤 일관성 유지법

프롬프트에 고정 접미어를 붙여 톤을 묶는다. 예: `muted tone, soft lighting, minimal composition, no text`. 이 접미어를 파이프라인 상수로 두면 담당자가 바뀌어도 톤이 흔들리지 않는다. 컬러는 디자인 시스템 팔레트를 따르고, 이미지 위 텍스트는 항상 흰색으로 통일한다.

## 실패 시 대체안 (fallback)

생성 이미지가 저품질이거나 톤이 안 맞으면 아래 순서로 내려간다.

1. 프롬프트를 바꿔 재생성 (최대 2회)
2. Unsplash·Pexels에서 같은 무드의 무료 이미지로 대체
3. 그래도 없으면 **이미지 자리를 그 장의 핵심 내용을 담은 표(2~3행)로 대체**한다

3번이 최종 안전망이다. 이미지가 없어도 슬라이드는 완성된 상태로 나가야 한다.

> 3번을 "단색 배경 + 좌측 컬러 바"로 두면 안 된다. 컬러 바는 장식 도형이라 품질 게이트 AC3(시각 요소 ≥ 1)의 계수 대상이 아니어서, 안전망을 탄 슬라이드가 오히려 P0에 걸려 발행이 막힌다. 표는 계수 대상이므로 통과하고, 무엇보다 컬러 바와 달리 정보를 담는다. 이 충돌은 표지·섹션 구분에서는 생기지 않는다 — 렌더 PNG 자체가 그림으로 잡히기 때문이며, 레이아웃 3(본문+이미지)에서만 발생한다.

## 파일 용량 관리

두 기준은 층위가 다르다. 섞어 쓰지 않는다.

- **이미지 1장**: 200KB 이하 권장, 500KB 초과 금지. 초과하면 재압축한다.
- **.pptx 파일 전체**: 8MB 한도. 초과하면 이미지 전체를 일괄 재압축한다.

## 금지 사항

- 한글 텍스트가 들어가는 그래픽을 이미지 생성 모델로 만들지 않는다. 글자가 깨진다.
- 프롬프트에 특정 작가·브랜드 스타일을 지정하지 않는다.
- 라이선스가 확인되지 않은 이미지를 고객 제출본에 넣지 않는다.
- **출처가 확인되지 않은 수치는 슬라이드에 넣지 않는다.** 라벨을 달아 통과시키지 않는다 — 회사 규칙은 표기 규칙이 아니라 차단 규칙이며, 품질 게이트에서 P0로 막힌다.
