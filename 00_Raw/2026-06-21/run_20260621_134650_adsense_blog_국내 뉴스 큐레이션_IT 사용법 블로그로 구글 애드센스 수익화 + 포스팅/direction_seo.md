# 블로그 방향 선택 + SEO 전략

## 1. 방향 3안 비교 (뉴스 큐레이션 vs IT 사용법 vs 혼합형)
| 방향 | 장점 | 단점 | 애드센스/정책 리스크 |
|---|---|---|---|
| 뉴스 큐레이션 | 저작권 문제 없음, 초기 유입 빠름 | 중복콘텐츠 위험, 정책 위반 가능성 | 저작권 위반, 스팸 콘텐츠 금지 |
| IT 사용법/툴 가이드 | 고단어 키워드, 안전한 애드센스 정책 | 일관성 부족 가능, 초기 유입 어려움 | -
| 혼합형 | 다양한 주제로 유입 빠름, 애드센스 승인 가능성 증대 | 콘텐츠 복잡도 증가, 일관성 유지 어려움 | -

## 추천 방향 + 근거 (부트스트랩 1인 + 자동화 전제)
**추천 방향: IT 사용법/툴 가이드**
- **근거:** 고단어 키워드로 SEO 성능 높이고, 애드센스 정책 위반 위험 낮음.
- **부트스트랩 1인 + 자동화:** 1인 부트스트랩 구조에서 효율적인 콘텐츠 생산과 유지 관리 가능.

## 첫 4주 SEO 키워드 전략 (주차별 롱테일 키워드 묶음)
- **1-2주**: 'AI 툴 사용법', '코드 최적화 기법', '데이터베이스 관리 기초'
- **3-4주**: '클라우드 서비스 비교', '머신러닝 도구 소개', '코딩 팁'

## 초기 유입 채널 (검색 SEO + 보조 1~2개)
- **검색 SEO:** 고단어 키워드로 초기 트래픽 확보
- **보조 1:** Reddit 활동: AI 사용법 및 툴 관련 커뮤니티에서 활동
- **보조 2:** 내부 링크 구조 강화: 기존 콘텐츠와 신규 콘텐츠 간 연결성 높이기
