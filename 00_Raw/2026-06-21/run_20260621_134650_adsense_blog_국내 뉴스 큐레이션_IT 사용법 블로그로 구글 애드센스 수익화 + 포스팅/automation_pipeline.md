# 포스팅 자동화 파이프라인 (n8n + 로컬 LLM)

## 아키텍처 개요 (키워드발굴 → AI초안 → 검수 → 게시)
- 키워드 발굴에서 AI 초안 작성, 검수, 게시까지의 전체 과정을 자동화합니다.

## n8n 노드 흐름 (트리거 → 키워드소스 → LLM생성 → 변환 → CMS게시 → 알림)
- **트리거**: 매일 특정 시간에 실행
- **키워드 소스**: AI가 사용할 검색어와 키워드 수집
- **LLM 생성**: 로컬 LLM qwen2.5-7b을 통해 AI가 초안 작성, 사람 개입으로 품질 보증 및 중복 방지
- **변환**: 생성된 마크다운 형식의 내용을 HTML로 변환
- **CMS 게시**: 변환된 HTML 파일은 WordPress CMS를 통해 자동으로 게시
- **알림**: 각 게시 작업이 완료되면 슬랙과 디스코드에 알림

## 게시 플랫폼 선택 (WordPress vs Next.js 자체 + 근거)
- **WordPress**: 대규모 컨텐츠 관리 및 SEO 최적화 지원
- **Next.js**: 개발 속도와 성능 향상, 레이어드 캐싱 가능

## 스케줄 (주 N편, 발행 시각, 사람 검수 개입 지점)
- 주 20편까지 처리: 로컬 LLM의 한계를 고려한 보수적인 추정
- 매일 특정 시간에 트리거 실행

## 로컬 LLM(qwen2.5-7b) 품질 한계 보완책
- AI가 작성한 초안은 반드시 추가 해설을 통해 독자에게 더 명확하고 구체적인 정보를 제공해야 합니다.
- 각 섹션별로 흐름을 분명하게 하여 콘텐츠의 일관성을 유지합니다.
- 원문 복제를 피하고, AI가 생성한 콘텐츠와 자체 해설 사이에 구분선을 두어 독자가 쉽게 이해할 수 있게 합니다.
