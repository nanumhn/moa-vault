# 네이버 블로그 자동화 SaaS — 사용자 플로우 + 관리툴 설계

## 전체 플로우 (가입 → 첫 자동발행 성공)
| 단계 | 사용자가 하는 일 | 화면 | 시스템이 하는 일 | 소요 |
|---|---|---|---|---|
| 1. 가입 | 사용자의 이메일과 이름을 입력하여 가입 페이지를 통과 | 가입 페이지 | 사용자 정보 저장 및 휴대폰 인증 요청 | 2분 |
| 2. 블로그 연결 | 네이버 ID와 비밀번호를 입력하여 블로그 계정을 연결 | 블로그 연결 화면 | 블로그 세션 생성 및 사용자 정보 저장 | 3분 |
| 3. 구글시트 연동 | Google Sheets API를 통해 구글시트에 접근하고, 콘텐츠 주제 관리 페이지로 이동 | 구글시트 연동 화면 | Google Sheets API 초기화 및 연결 상태 확인 | 5분 |
| 4. 콘텐츠 주제 등록 | 사용자가 작성한 콘텐츠 주제를 구글시트에 추가 | 콘텐츠 주제 관리 페이지 | 콘텐츠 주제 데이터베이스 저장 및 검증 | 10분 |
| 5. 예약 설정 | 자동 발행을 원하는 날짜와 시간을 선택하고, 시스템으로 설정 전송 | 예약 설정 화면 | 사용자의 예약 정보 저장 및 스케줄러 초기화 | 3분 |
| 6. 자동 발행 | 정해진 날짜와 시간에 자동으로 포스팅이 작성되어 올라가고, 결과 확인 페이지로 이동 | 자동발행 중 | 시스템은 예약 정보를 참조하여 자동으로 포스팅 수행 및 상태 알림 전송 | 10분 |
| 7. 결과 확인 | 자동 발행 실패 여부와 포스팅 결과 확인 | 결과 확인 페이지 | 사용자에게 성공/실패 메시지 전달 | 2분 |

## 정보 등록 화면 — 입력 항목 최종
| 필드 | 설명 | 필수 | 검증 규칙 |
|---|---|---|---|
| 네이버 ID | 사용자가 네이버 블로그에 로그인할 때 사용하는 아이디 | 예 | 정규표현식 유효성 검사 |
| 비밀번호 | 사용자가 네이버 계정을 보호하기 위해 설정한 비밀번호 | 아니오, 별도의 세션 관리로 대체 | 비밀번호 확인 |
| 네이버 블로그 주소 | 사용자의 네이버 블로그 URL | 예 | 정규표현식 유효성 검사 |
| 구글시트 ID | Google Sheets API를 통해 접근할 구글 시트의 ID | 아니오, 별도로 구글시트 연동을 통한 관리 | 비밀번호 확인 없음 |
| 콘텐츠 템플릿 설정 | 포스팅 내용 기반으로 템플릿 작성 | 예 | 텍스트 길이 유효성 검사 |

## 구글시트 연동의 용도 (한 문장 확정)
- 확정: 사용자가 작성한 콘텐츠 주제 목록을 저장하고 관리하는 역할입니다.
- 시트 컬럼 구조 제안:
  - ID
  - 주제명
  - 작성자

## 대시보드 첫 화면에 보여야 할 것 (우선순위 순 5개)
1. 사용자 이름
2. 로그인 상태 표시
3. 시스템 상태 표시
4. 예약된 발행 일정 확인
5. 최근 자동발행 결과

## 발행 실패 시 처리
- 알림 방법: 사용자에게 자동발행 실패 사유 메일로 알리기
- 사용자 선택지: 재시도 옵션 제공 및 직접 포스팅할 수 있는 링크 제공
- 자동 재시도 정책: 최대 3회까지 시도, 재시도 실패 시 사용자에게 안내 메시지 전송

## 사용자가 이탈할 위험이 가장 큰 단계와 대책
- 위험한 단계: 구글시트 연동과 콘텐츠 주제 등록
- 대책:
  - 구글시트 연동 화면에서 인증 절차를 간소화하고, 사용자가 안전하게 접근할 수 있도록 도우미 가이드 제공
  - 콘텐츠 주제 등록 페이지에서는 미리 작성된 템플릿을 제안하여 사용자 부담을 줄이고, 필요한 경우 추가 설명 제공
