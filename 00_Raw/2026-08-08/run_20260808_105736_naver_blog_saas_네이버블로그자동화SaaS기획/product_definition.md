# 네이버 블로그 자동화 SaaS — 제품 정의서

## 한 문장 정의
여러 명(멀티테넌트)이 각자 네이버 블로그 계정 정보를 등록하면 매일 정해진 시간에 글을 대신 써서 올려주는 구독형 SaaS 서비스.

## 형 초안 가설 검증
- 형의 가설: '여러 명(멀티테넌트)이 각자 네이버 블로그 계정을 등록하면 매일 정해진 시간에 글을 대신 써서 올려주는 구독형 SaaS'
- 이 정의가 맞는가: 맞음 + 근거: 형의 가설이 기존 회의 내용과 일치하므로 수정 없이 사용 가능.
- 최종 정의: '여러 명(멀티테넌트)이 각자 네이버 블로그 계정 정보를 등록하면 매일 정해진 시간에 글을 대신 써서 올려주는 구독형 SaaS'

## 1순위 타깃 고객 페르소나
- 직업: 자영업자, 병원/학원 원장, 부동산 중개사, 1인 마케터, 블로그 대행사
- 왜 블로그를 해야만 하는가 (고통): 브랜딩, 콘텐츠 공유, 소비자 관계 강화의 필요성.
- 지금은 뭘로 때우고 있는가 (대체재): 직접 글쓰기, 사람으로 대행받는 서비스
- 얼마까지 낼 의향이 있는가: 48만원 이하

## 2·3순위 타깃 (간단히)
- 2순위: 블로거
- 3순위: 뉴스 기사 작성자

## 경쟁 대비 차별점
| 대체재 | 월 비용 | 우리 대비 약점 |
|---|---|---|
| 사람이 하는 블로그 대행 | 50만원 ~ 100만원 | 자동화 비용, 시간 소요 |
| 직접 쓰기 | 무료 | 품질 저하, 시간 소요 |
| 다른 AI 글쓰기 툴 | 30만원 ~ 60만원 | 검색 노출 제한, 품질 불안정 |

## 핵심 가치 1개 (MVP에서 이것만은 지킨다)
- 자동발행과 검색 노출 확보

## 팔리지 않을 위험 (솔직하게 2개)
1. **네이버 블로그 글쓰기 공식 API 발급 불가능**: 네이버 API를 사용하지 못하면, 에이전트 방식으로 구현해야 하며, 이는 성능과 비용 측면에서 제한적일 수 있다.
2. **사용자의 개인정보 침해 리스크**: 계정 정보를 직접 보관하지 않는 대신, 사용자가 세션을 직접 연결하거나 본인 PC에서 프로그램을 실행하는 방식으로 로그인 및 포스팅을 진행하여 안전성을 높일 수 있지만, 이를 구현하기 어렵고 사용자 편의성에 악영향을 줄 수도 있다.
