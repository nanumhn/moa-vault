# 네이버 블로그 자동화 SaaS — 제품 정의서

## 한 문장 정의
여러 명이 각자 네이버 블로그 계정 정보를 등록하면 매일 정해진 시간에 글을 대신 써서 자동으로 올려주는 구독형 SaaS 서비스입니다.

## 형 초안 가설 검증
- 형의 가설: '여러 명이 각자 네이버 블로그 계정을 등록하면 매일 정해진 시간에 글을 대신 써서 올려주는 구독형 SaaS'
- 이 정의가 맞는가: 맞음 + 근거
- 수정된 최종 정의: 여러 명이 각자 네이버 블로그 계정 정보를 등록하면 매일 정해진 시간에 글을 대신 써서 자동으로 올려주는 구독형 SaaS 서비스입니다.

## 1순위 타깃 고객 페르소나
- 직업: 자영업자, 병원/학원 원장, 부동산 중개사, 1인 마케터, 블로그 대행사
- 왜 블로그를 해야만 하는가 (고통): 시간이 없거나 글쓰기가 어려워 블로그 운영을 포기하거나 효율성이 낮은 상태
- 지금은 뭘로 때우고 있는가 (대체재): 직접 글 쓰는 것, 사람에게 블로그 대행 서비스 이용
- 얼마까지 낼 의향이 있는가: 48만원/월

## 2·3순위 타깃 (간단히)
- 2순위: 블로거(일주일에 한 번 이상 포스팅하는 사람들)
- 3순위: 일반 사용자(시작 단계에서 블로그 운영을 도와줄 필요가 있는 사람들)

## 경쟁 대비 차별점
| 대체재 | 월 비용 | 우리 대비 약점 |
|---|---|---|
| 사람이 하는 블로그 대행 | 100만원 이상 | 비용이 비싸고 시간 소요 |
| 직접 쓰기 | 무료 | 시간 소모, 글쓰기 능력 제한 |
| 다른 AI 글쓰기 툴 | 30만원 이상 | 품질 불안정, 검색 노출 제한 |

## 핵심 가치 1개 (MVP에서 이것만은 지킨다)
- 자동발행과 검색 노출 확보

## 팔리지 않을 위험 (솔직하게 2개)
1. 네이버 블로그 글쓰기 API가 신규 발급되지 않으면 기능 제한
2. 사용자의 개인정보 침해 리스크로 인한 신뢰도 저하
