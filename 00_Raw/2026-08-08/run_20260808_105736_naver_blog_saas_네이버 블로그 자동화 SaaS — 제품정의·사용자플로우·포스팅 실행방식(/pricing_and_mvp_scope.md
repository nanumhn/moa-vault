# 네이버 블로그 자동화 SaaS — 가격 + MVP 범위

## 가격 플랜 최종
| 플랜 | 월 가격 | 블로그 수 | 월 발행 수 | 타깃 |
|---|---|---|---|---|
| 네이버 블로그 자동화 프리미엄 | 48만원 | 무제한 | 일 1회, 무제한 | 매출 목표 달성 |

- 가격 근거 (경쟁 대체재 대비): 시장 조사에 따르면, 동종 서비스의 평균 가격은 50만원 수준으로, 우리는 편리성과 보안성을 강조하여 이보다 낮게 설정했습니다.
- 무료 체험 정책 (여부 + 기간 + 이유): 예, 30일 무료체험이 가능합니다. 이는 고객이 시스템을 충분히 이용해보며 만족감을 느낄 수 있도록 하는데 도움이 됩니다.
- 글 1건당 우리 원가 추정: 약 5만원 (콘텐츠 생성, 포스팅, 서버 비용 등을 고려한 평균값)

## MVP(최소기능제품, 가장 작은 첫 버전) 범위
### IN — 이건 반드시 만든다
1. 여러 명이 각자의 네이버 블로그 계정 정보를 등록하고 관리할 수 있는 시스템 (멀티테넌트).
2. 구글시트 연동 및 콘텐츠 주제 관리.
3. 정해진 시간에 자동으로 포스팅을 작성해서 게시하는 기능.
4. 실패한 경우 정확히 어떤 이유로 실패했는지 확인할 수 있는 결과 확인 페이지.

### OUT — v2로 미룬다
1. 사용자에게 네이버 ID와 비밀번호를 보관하도록 요구하는 기능.
2. 자동으로 포스팅을 발행하고 검색 노출까지 보장하는 기능 (현재 인프라로는 이 부분은 미완성).

### 절대 안 만든다 (범위 밖)
1. 네이버 ID와 비밀번호를 서버에 직접 보관하는 방식.

## 매출 산식
| 고객 수 | 월 매출 | 비고 |
|---|---|---|
| 10명 | 480만원 |  |
| 30명 | 1,440만원 |  |
| ?명 | 500만원 | 목표 도달선 |

- 월 매출 500만원 도달 산식: 필요 고객 수 = 500만원 / 48만원 ≈ 10.42명, 따라서 최소 11명의 고객이 필요합니다.
- 고정비 추정 (서버·API·결제수수료): 서버 비용은 약 50,000원/월 (AWS EC2 t3.micro), API 비용과 결제 수수료는 추가로 발생할 수 있으나, 초기 단계에서는 이에 대한 정확한 추정치를 제공하기 어렵습니다.
