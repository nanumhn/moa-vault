# 신규 글로벌 다채널 사업 — 전략·아이템·결정

## 아이템 롱리스트 (5개 이상, 음악·사주 제외)
1. **AI 이미지 배치 사이트 / AI Image Batch Generator**
   - 정의: AI 기반 이미지 생성 및 배치 서비스
   - 타깃: 디자이너, 마케터, 웹사이트 운영자
   - 주력 수익 채널: 구독, 광고(AdSense), 제휴 파트너십
   - 우리 자산 활용: ComfyUI, n8n

2. **AI 아바타 생성기 / AI Avatar Generator**
   - 정의: AI 기반 인물 이미지 생성 서비스
   - 타깃: SNS 운영자, 캐릭터 디자이너
   - 주력 수익 채널: 구독, 광고(AdSense), 제휴 파트너십
   - 우리 자산 활용: ComfyUI, n8n

3. **노션템플릿 상점 / Notion Template Store**
   - 정의: AI 기반 Notion 템플릿 생성 및 판매 서비스
   - 타깃: 비즈니스 고객, 프로젝트 관리자
   - 주력 수익 채널: 구독, 광고(AdSense), 디지털 상품 판매
   - 우리 자산 활용: Qwen2.5-7b, n8n

4. **AI 스토커 생성기 / AI Sticker Pack Creator**
   - 정의: AI 기반 스티커/이모티콘 팩 생성 서비스
   - 타깃: 캐릭터 디자이너, 앱 운영자
   - 주력 수익 채널: 구독, 광고(AdSense), 제휴 파트너십
   - 우리 자산 활용: ComfyUI, n8n

5. **AI 컬러링북 생성기 / AI Coloring Book Creator**
   - 정의: AI 기반 컬러링북 생성 서비스
   - 타겟: 아동 교육자, 디자이너
   - 주력 수익 채널: 구독, 광고(AdSense), 디지털 상품 판매
   - 우리 자산 활용: Qwen2.5-7b, n8n
