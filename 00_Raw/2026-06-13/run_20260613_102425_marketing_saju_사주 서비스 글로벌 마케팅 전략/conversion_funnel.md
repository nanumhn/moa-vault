# 사주 서비스 전환 퍼널

## 퍼널 단계 정의 (방문 → 가입 → 무료체험 → 유료)
1. 방문: TikTok, YouTube Shorts, Reddit 등에서 유입
2. 가입: 웹사이트에서 사주 서비스를 체험하기 위해 가입
3. 무료체험: 3회 무료 시도 기회 제공
4. 유료: 무료체험 후 유료 구독으로 전환

## 단계별 이탈 방지 레버
1. 방문: 강력한 훅 카피와 콘텐츠로 관심을 잡는다.
2. 가입: 간편한 가입 프로세스와 청명한 인터페이스를 제공한다.
3. 무료체험: 유용한 사주 해석 예시와 사용자 참여 챌린지로 흥미를유발한다.
4. 유료: 명확한 가치 proposition과 유료 구독 이점 설명으로 유도한다.

## 전환율 가정 (각 단계 %)
1. 방문 → 가입: 2%
2. 가입 → 무료체험: 75%
3. 무료체험 → 유료: 6.67%

## 첫 결제 오퍼 설계 (무료→유료 전환 장치, 가격 앵커링)
- 무료 시도 후 첫 구독 시 $4.99 할인 제공
- 90일 동안 할인 적용

## 체크아웃 개선 (PayPal 흐름 기준 1~2개)
1. 결제 페이지에서 단계별 안내와 명확한 정보 제공
2. 결제 후 사용자에게 인증 메시지 보내기

## A/B 테스트 안 2개
1. PayPal Sandbox 환경에서 결제 버튼 색상과 언어 변경
2. 첫 구독 시 할인 옵션 추가
