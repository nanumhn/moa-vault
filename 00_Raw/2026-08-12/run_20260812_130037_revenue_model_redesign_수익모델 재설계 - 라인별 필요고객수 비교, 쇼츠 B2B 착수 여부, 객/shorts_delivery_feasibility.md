## 2. 캐파 추정
- 월 최대 납품 가능 편수: 10편 + 8주간 준비 기간을 고려하면, 실제 월 평균 7편.
- 편당 소요: 사람 손 (3분) / GPU (2분) / API 비용 (₩0)
- 편당 실제 원가 (₩15,000)

2. 대행사용
3. 형에게 보고용

## 5. 납품 SLA 초안 (계약에 박을 수준)
- 납기: D+7부터 8주간, 최대 6개월
- 수정 횟수: 1회 수정까지
- 해상도/규격: 1080p, 30fps, SDI 연결
- 자막 규격: CC 자막
- 소스 저작권 처리: 소유자 명시 및 이용허가

## 6. 리스크 2개 + 회피책

- **리스크**: 초기 딜 잡기에 실패하는 경우.

### 리스크 2
- **리스크**: 납품 SLA 위반 가능성.
- **회피책**: 초기 SLA에 명확한 기준을 설정하고, 이행하지 않을 경우 즉시 조치.
