# 2026-08-14 오후~야간 — nBlog "AI 본문자동화" 기능 신규 구축

## 요약
형이 오전에 확정한 요구사항(가격정책·회원등급·베타멤버)을 이어받아, "SI업체 방식 6단계 프로세스"(기획→설계→개발→QA→배포→운영보고)를 이 기능의 1호 케이스로 적용해서 체크리스트 9개 항목을 하루 만에 전부 완수했다.

## 기능 개요
사용자가 구글시트 J열(키워드) 또는 대시보드에 키워드를 입력하면, 서버 배치(하루 2회 트리거+5분마다 워커)가 GPT API로 nBlog 문법 본문+이미지(무료스톡2장+AI생성1장)를 만들고, 사용자가 시트 A열 토큰(자동발행/초안검수/검수완료) 또는 대시보드 승인버튼으로 검토·승인하면 실제 네이버 블로그에 발행된다.

## 가격정책 (형 확정, 2026-08-14)
- 유료회원 애드온: 블로그당 월 2만원, 60편/월 캡
- 프리미엄회원 애드온: 블로그당 월 1.5만원(3블로그 묶으면 4.5만원, 유료대비 25%할인, 편당250원) — sales-head-jio 산정
- 베타멤버: 프리미엄+애드온 묶음 무료제공(피드백 대가)
- 원가: 텍스트(gpt-5.6-terra) 편당 38원 + 이미지(gpt-image-2 low) 장당 7원 → 편당 약45원, 목표 50원 이내

## 구현 순서 (체크리스트 9개)
1. 설계문서 업데이트(회원등급 매트릭스, 배치스케줄 설계)
2. 회원등급·권한게이팅(무료/유료/프리미엄/베타멤버)
3. 키워드 입력 파이프라인 — AiDraftJob 신규 큐테이블(기존 글감테이블 확장 대신 별도테이블로, sheet-sync 무한증식버그 원천차단)
4. GPT API 연동(텍스트+이미지), Pexels 실호출 성공
5. 배치스케줄러(서버crontab, KST 04:10/14:10, 형PC세션에 안 묶음 — 설계문서 UTC 오기재 발견수정)
6. 검토대기 UI(시트A열 3토큰, write-back, 조건부서식, 대시보드 승인버튼)
9. 크레딧 계정당공유→블로그당개별 60편 전환
