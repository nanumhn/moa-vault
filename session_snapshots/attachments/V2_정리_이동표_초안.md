## 4. 반영 방법 — 형 결정 필요
현재 스크립트는 추적 파일이 사라지면 멈춘다. 로컬에서는 `deletion or unusual file type`(246행), 다른 PC에서는 `remote deletion`(282행)으로 STOP한다. 그래서 이동·이름 변경은 자동 동기화로 올라가지 않는다.

- **A안(내가추천)**: 아래 순서로 한 번에 반영한다.
  1. 클로PC 예약 동기화 중지
  2. 형은 Obsidian을 잠시 닫는다(편집 중 충돌과 줄바꿈 재작성 방지)
  3. 작업 전 동기화
  4. `git mv`로 이동·이름 변경, 링크 수정
  5. 커밋 1개 `[sync][클로PC] V2 폴더 정리·일지 이름 변경`을 일반 push(강제 아님)
  6. 원격 반영 확인 후 예약 재가동

  **영향**: 개발PC1 등 다른 PC의 예약 동기화는 한 번 `remote deletion` STOP이 난다. 그 PC에서 오늘과 같은 수동 절차(예약 중지 → `fetch` → `merge --ff-only` → 스크립트 실행 → 예약 재가동)로 한 번 받아야 한다.
- **B안**: 스크립트를 관리하는 쪽(개발PC1)이 먼저 "이동·이름 변경 허용"을 스크립트에 넣은 뒤 진행한다. 다른 PC를 손대지 않아도 되지만, 스크립트 수정이 먼저 필요하다.
