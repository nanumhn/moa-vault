형이 2026-05-29 제시한 Moa Studio의 장기 방향. 단순 음악 파이프라인을 넘어 **자율 멀티 에이전트 회사**로 키우는 것.

**비전 (5개 기둥):**
1. 프로젝트 지시 — 형이 "프로젝트 N 해줘" 던짐 (Suno 파이프라인=프로젝트1, 이후 2/3/4...)
2. 총괄 할당 — COO/총괄이 받아 적합 직원/팀에 임무 분배
3. 자율 실행 — 완료(goal)까지 스스로 (회의→작업→평가→반복), 사람 개입 최소
4. 비서 보고 — 진행/결과를 비서가 Discord로 형에게 보고
5. 학습 & 자기개선 — 회의로 생성된 지식이 각 직원에게 축적 → 다음 프로젝트에 더 잘 활용 → 페르소나가 스스로 업그레이드

**Why:** 형은 한 번 던지면 알아서 끝까지 굴러가고, 할수록 똑똑해지는 조직을 원함. agent-town 픽셀 오피스([[reference-agent-town]])는 이 시스템의 진행상황을 보는 비주얼 레이어로 활용 희망 ("아기자기한게 맘에 든다").

**이미 가진 것 (재활용):** 회의 엔진(localhost:8080), Suno 파이프라인(프로젝트1 사례), 직원 페르소나(이서아 A&R / 한지오 SEO / 박진형 작사 / 클로 개발 등), Discord 봇(비서 보고 채널), [[pipeline-progress-2026-05-15]].

**새로 만들 것:** ①프로젝트 오케스트레이터(지시 파싱→작업 분해→할당→완료 판정) ②자율 실행 루프 ③직원 지식 베이스(회의 산출물→직원별 메모리, RAG/벡터DB or 파일) ④자기개선 루프(학습→페르소나 프롬프트 진화).

**How to apply:** 새 "프로젝트 N" 지시가 오면 이 오케스트레이션 틀로 해석. 시작점 옵션 제시함 — (A)오케스트레이터+비서보고 코어 먼저[추천] (B)픽셀 비주얼 먼저 (C)지식학습 먼저. 형 결정 대기 중(2026-05-29). 대형 설계라 회의 엔진으로 직원 의견 소집하는 것도 옵션으로 제안함.
