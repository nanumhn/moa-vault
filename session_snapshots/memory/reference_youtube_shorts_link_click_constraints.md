쇼츠 기반 제휴·유입 설계를 할 때마다 다시 부딪히는 플랫폼 제약. 2026-08-17 아투 쿠팡파트너스 건에서 확인.

**클릭 안 되는 곳**
- 쇼츠의 **설명란·댓글에 넣은 일반 URL은 클릭 불가능 처리**된다. 유튜브 공식 정책:
  https://support.google.com/youtube/answer/13748639
  → "설명란에 제휴 딥링크를 넣어 전환을 받는다"는 기획은 원리적으로 성립하지 않는다.

**클릭 되는 곳 두 군데**
1. **유튜브 쇼핑 제휴 프로그램** — 단, YPP 가입(구독 1,000+·시청 4,000시간) 위에 **구독자 1만 명 초과**가 추가 요건. 신생 채널은 못 쓴다.
2. **채널 프로필 링크** — 조건 없음. 채널 홈에 최대 14개까지 넣지만 **첫 번째 링크만 프로필 섹션(구독 버튼 근처)에 노출**되고 나머지는 "더보기" 뒤에 숨는다. 그래서 첫 링크 자리는 하나뿐인 자산이다.

**자동화 한계**: YouTube Data API v3 `channels.update`의 `brandingSettings`에는 링크 속성이 없다(description·keywords·배너는 됨). 프로필 사진과 마찬가지로 **API로 설정 불가 → 유튜브 스튜디오에서 사람이 직접** 눌러야 한다. 경로: 스튜디오 → 맞춤설정 → 기본 정보 → 링크 → 추가 후 **맨 위로 드래그** → 게시.

**How to apply**: 쇼츠에서 외부 전환을 만들려는 설계가 올라오면, 먼저 "링크가 클릭되는 자리인가"부터 확인할 것. 실질 경로는 채널 프로필 첫 링크 하나뿐이고, 시청자는 쇼츠→채널아이콘→채널홈→링크로 최소 3~4번을 눌러야 하므로 전환율 기대치를 그에 맞게 잡는다. 설명란 코드를 통째로 버릴 필요는 없다 — 클릭은 안 돼도 **공정위 대가성 고지의 게시 위치**로는 여전히 필요하다.
