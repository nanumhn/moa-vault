형이 Discord로 보낸 첨부(사진·파일)는 로컬 디스크의

```
C:\Users\user\.claude\channels\discord\inbox\
```

에 저장된다. 파일명은 `<타임스탬프>-<메시지ID>.jpg` 꼴이다.

2026-08-21 타로 그림체 작업에서 형이 마르세유 타로 사진을 보냈는데, 나는
`Downloads` 와 temp 폴더만 뒤지고 "사진이 제 쪽에 없습니다" 라고 보고했다.
실제로는 계속 이 폴더에 있었다. **참고 이미지가 필요하면 형에게 다시 보내달라고
하기 전에 여기부터 확인할 것.**
