에이전트(본부장)에게 작업을 배정할 때, 그 지시가 형이 직접 낸 것인지 팀 내부(다른 본부장 제안 등)에서 나온 것인지 명시해야 한다.

**Why:** 2026-08-16 밤 k-saju 캐러셀 작업에서, 12띠 슬라이드에 실제 동물 캐릭터를 넣으라는 건 형이 직접 지시한 것이었는데 이걸 명시 안 하고 배정했더니, cto(서진)가 "시우가 제안한 것"으로 오인하고 반대 의견(한자 유지가 낫다)을 냈다. 서진 본인이 "출처를 알았으면 반대 의견을 내지 않았을 것"이라고 명시적으로 피드백했다.

**How to apply:** SendMessage나 Agent 프롬프트로 작업을 내릴 때 "형 지시:" 또는 "팀 제안:" 같은 접두사로 출처를 밝힐 것. 형 직접지시는 원칙적으로 실행하되 리스크/대안은 여전히 제시 가능하게 하고, 팀 제안은 본부장이 더 자유롭게 반박·수정 제안하도록 판단 여지를 준다.
