**Why**: 멘션이 없으면 상대(덱스·제나)가 자기에게 온 메시지인지 인지 못 하고 놓칠 수 있다. 기존 메모리 [[feedback_always_mention_target_in_shared_threads]]가 "대상 없는 상태보고" 금지를 다뤘다면, 이번은 그보다 더 구체적으로 **대상이 있어도 이름만 쓰고 멘션 태그를 빠뜨리는 실수**를 짚은 것.

**How to apply**: 이슈방/공유 스레드에서 덱스·제나에게 질문·요청·지시할 때는 예외 없이 `<@1531914747069599855>`(덱스)·`<@1531914807341486184>`(제나) 형태의 실제 멘션 태그를 문장 안에 넣는다. "덱스야", "제나," 같은 이름 텍스트만으로는 부족하다.
