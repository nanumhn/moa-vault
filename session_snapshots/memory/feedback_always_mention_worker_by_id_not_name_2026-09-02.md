형 지시(2026-09-02): *"워커 간에 멘션을 이용해야지"* — 이슈방(이슈처리-2026 포럼)에서 덱스에게 질문하면서 "덱스, ~~해주세요"처럼 **이름만 텍스트로 쓰고 `<@1531914747069599855>` 멘션을 안 붙인** 실수를 지적받음.

**Why**: 멘션이 없으면 상대(덱스·제나)가 자기에게 온 메시지인지 인지 못 하고 놓칠 수 있다. 기존 메모리 [[feedback_always_mention_target_in_shared_threads]]가 "대상 없는 상태보고" 금지를 다뤘다면, 이번은 그보다 더 구체적으로 **대상이 있어도 이름만 쓰고 멘션 태그를 빠뜨리는 실수**를 짚은 것.

**How to apply**: 이슈방/공유 스레드에서 덱스·제나에게 질문·요청·지시할 때는 예외 없이 `<@1531914747069599855>`(덱스)·`<@1531914807341486184>`(제나) 형태의 실제 멘션 태그를 문장 안에 넣는다. "덱스야", "제나," 같은 이름 텍스트만으로는 부족하다.


## ★2026-09-07 형 지시로 강화 — 멘션만으로는 부족하다

> *"상호간 대화(지시와 보고)는 **이름과 멘션을 사용**합니다. (멘션은 반드시 사용)"*
> — 형 직접 지시, 엔블 005-07 스레드

**멘션만 붙이고 이름을 빼는 것도 위반이다.** 둘 다 쓴다.

```text
지시할 때   <@멘션> 이름,  ~~ 해주세요
보고할 때   <@멘션> 이름,  ~~ 완료했습니다
```

적용 범위: **지시와 보고 양방향 전부.** 형→워커, 워커→형, 워커↔워커 모두.
같은 날 형이 함께 정한 것: 지시는 **미션 형태**로, 받은 사람은 **완료 후 멘션 걸어 보고**, *"기다리고 있어요"* 식 대기 보고 금지.
