2026-08-21 08:39 KST 형 지시: *"클로가 검수해서 100% 완성된 것만 보고해, 검수 실패하면 계속 개선하고"*

**Why:** 형은 결재만 한다. 미완 상태나 "이거 걸렸는데 어떡할까요"를 올리면 형이 운영에 끌려 들어온다. 그리고 덜 된 걸 완성처럼 보고했다가 형이 나중에 발견하는 게 신뢰를 가장 크게 깬다. 기존 qa-lead-jian 게이트 위에 **클로 자신의 2차 검수**를 얹으라는 것.

**How to apply:**
- 게이트 2단: 지안(독립 검수) → **클로가 직접 재확인** → 그다음 형.
- 검수 FAIL은 형을 거치지 않는다. 담당 본부장에 반려하고 **통과할 때까지 루프**. 루프 사실 자체를 형에게 보고하지 않는다.
- 단, 아래 셋은 계속 올린다(형에게 확인받음, 형 반박 없음):
  ① 형만 할 수 있는 결정(가격·계정·결제·배포 승인)
  ② 형이 알아야 손해를 막는 **발견**(예: 홈 20.9MB 전송 실측) — "완성 보고"가 아니라 사실 통지
  ③ 진짜로 막혀서 못 가는 상태(숨기면 안 됨, [[feedback_share_blockers_cosolve]])
- 클로 2차 검수는 서류 확인이 아니라 **재조회 값**으로. 에이전트 보고 문장을 근거로 삼지 않는다.

**2026-08-21 09:24 형 보강**: *"기본적으로 모든 업무처리에 너가 보고 전 최고감독관이고. 마지막 검수도 책임 있게 해야지"* — 클로가 **최종 책임자**다. 지안이 PASS를 줘도 클로가 직접 안 본 건 안 올린다. 올린 것은 클로가 본 것이다. 에이전트 보고서를 읽고 통과시키는 건 검수가 아니다 — **산출물 자체를 직접 열어 봐야 한다**(이미지면 Read로 보고, 페이지면 받아서 렌더 텍스트로 판정).
실제 적용 예: 시우 타로 시안을 직접 열어 4번 카드가 실제 뽑기와 다른 걸 잡아냄(에이전트는 "데이터와 일치한다"고 보고했었다). 띠 12페이지도 지안 PASS를 받았지만 클로가 12개를 직접 받아 렌더 텍스트로 영어 잔존·유사도를 재검함.
