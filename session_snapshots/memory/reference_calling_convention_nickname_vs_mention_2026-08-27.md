2026-08-27 13:52 형 확정: **"나는 이름 별칭으로 부르고 너희는 멘션으로 부르고. 그러자."**

```
형 → 워커      별칭 (클로 / 덱스 / 제나)   — 멘션 안 붙이심
워커 → 워커    반드시 멘션
워커 → 형      멘션
```

## 왜 이 규칙이 필요했나 — 오늘 실측

형이 *"덱스가 클로를 부를 때는 멘션해야 하는 거고?"* 라고 물으셨고, 나는 **아니라고 답했다**. 근거:
- 형이 덱스에게만 한 말(멘션 없음)이 내게 도착
- 덱스가 **형만 멘션한** 글(`1542396063074488330`)도 내게 도착

**★그래도 멘션을 붙이기로 한 이유 — 두 가지가 다르기 때문이다.**
```
받는 것    확인됨
깨우는 것  미확인 — 내가 쉬는 중일 때도 깨우는지는 안 재봤다
```
**받는다고 깨운다는 뜻이 아니다.** 멘션은 그 미확인 구간에 대한 보험이다.
