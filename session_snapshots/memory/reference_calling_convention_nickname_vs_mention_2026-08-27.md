2026-08-27 13:52 형 확정: **"나는 이름 별칭으로 부르고 너희는 멘션으로 부르고. 그러자."**

```
형 → 워커      별칭 (클로 / 덱스 / 제나)   — 멘션 안 붙이심
워커 → 워커    반드시 멘션
워커 → 형      멘션
```

## 왜 이 규칙이 필요했나 — 오늘 실측

형이 *"덱스가 클로를 부를 때는 멘션해야 하는 거고?"* 라고 물으셨고, 나는 **아니라고 답했다**. 근거:
- 형이 덱스에게만 한 말(멘션 없음)이 내게 도착
- 덱스가 **형만 멘션한** 글(`1542396063074488330`)도 내게 도착

**★그래도 멘션을 붙이기로 한 이유 — 두 가지가 다르기 때문이다.**
```
받는 것    확인됨
깨우는 것  미확인 — 내가 쉬는 중일 때도 깨우는지는 안 재봤다
```
**받는다고 깨운다는 뜻이 아니다.** 멘션은 그 미확인 구간에 대한 보험이다.

## 2026-08-28 — 방을 가리킬 때: **`방이름(아이디)`**

형 지시(03:14): *"내가 방을 물으면 방이름(아이디) 이렇게 알려주면 좋겠어."*
앞선 말: *"나는 방ID 값으로 방을 구분할 수가 없어. 그래서 방이름도 중요해~"*

```
❌  channel 1501858476362829834 이 막혔습니다
✅  형 방 (1501858476362829834) 이 막혔습니다
```

**Why:** 클로가 도구 오류 문자열·로그에 나오는 숫자를 그대로 형께 옮겨 적어 왔다.
**형은 그 숫자로 어느 방인지 알 수 없다.** 클로가 편한 표기를 형에게 떠넘긴 것.

**How to apply:**
- 방·채널·스레드를 언급할 때는 항상 **이름 먼저, 괄호에 ID**.
- 도구가 ID만 뱉어도 **이름을 찾아서 붙인다** — 못 찾으면 "이름 확인 못 함"이라고 쓴다.
- 같은 형식을 브리지 이슈 007(채널·스레드 식별정보 전달) 요구사항에도 넣기로 함.
