- **cron을 잠깐 통째로 잃었다.** 보류큐 cron 개선하려고 **기존 걸 먼저 삭제** → 새 CronCreate가 분류기에 막혀 한동안 cron 부재 상태. → **교체는 새 것을 만든 뒤 지운다.**

## 이번 세션에서 확인된 유용한 사실
- **`exit=0` ≠ 일이 됐다.** 원장(`publish_ledger.jsonl`)이나 산출물 재조회로 확인해야 한다. 복구 빌드도 exit=0으로 끝났지만 그건 무의미했고, 원장 `status=published` + 유튜브 `status=PUBLIC`으로 확인했다.
- **게이트가 "지어낸 인용"이라 잡아도 먼저 원문과 대조하라.** 8/19 2건 다 조작이 아니라 원문 괄호(`이것(한미 연합훈련 축소)이`)·소제목 축약 때문에 전체 문자열 대조가 깨진 것이었다. verbatim 복원하면 통과.
- bun 출력을 PowerShell로 리다이렉트하면 **UTF-16으로 떨어져 ASCII 사이에 NUL이 낀다.** 순진한 `-match`는 무조건 실패 → ASCII 디코드 후 NUL 제거 필요.
