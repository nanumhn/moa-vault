k-saju(케이사주) 인스타그램 데일리카드 계정을 **게시물당 1장 → 5장 캐러셀**로 전환하는 실험이 2026-08-16 기획 확정됐다. 개발 마감 8/20, 실험 8/21~9/3, 리뷰 9/4.

**Why:** 캐러셀이 단일이미지 대비 참여율 +52%(Socialinsider Q2 2026, 0.50% vs 0.33%), 도달 3배. 저장이 2026 인스타 배포 랭킹 1순위 신호인데 단일이미지로는 저장이 안 찍힌다. 목적은 조회수가 아니라 k-saju.me 유입.

**How to apply:**
- **"케익사주"는 형의 음성인식 오타 = "K사주"다.** 케익/케이크 컨셉은 존재하지 않으니 다시 등장하면 오타로 취급할 것. 초기 기획이 "케익 비주얼"을 전제로 설계됐다가 통째로 폐기됐다.
- 5장 구성 = 후킹 / 오늘의 패 / 해석 / **저장 유발(할 것·피할 것)** / CTA. 4번이 핵심 — 저장을 만드는 유일한 슬라이드다.
- 슬라이드 2·3은 saju-studio의 기존 OG 카드 라우트를 그대로 재사용하고, 1·4·5만 신규 레이아웃. 신규 창작 이미지는 0장.
- **★기준선 실측 결과 = 0 (8/16 형 인사이트 확인).** 최근 7개 게시물 조회 0~1·좋아요 0~2·저장 0·팔로우 0, 댓글 0~5는 봇 추정. → **6절 배수 역산식(B×1.5) 폐기.** 0에 곱하면 0이다.
- **★캐러셀 근거의 전제가 이 계정엔 성립하지 않는다.** Socialinsider 참여율은 분모가 팔로워 수라 팔로워 0이면 정의 불가, carouselli는 팔로워 5천~10만 구간 표본. 캐러셀은 발견 포맷이 아니라 **저장·전환 포맷**이라 기존 팔로워에게 배포된 뒤에야 작동한다. 팔로워 0 계정의 콜드스타트는 사실상 릴스뿐.
- **★같은 문제의 두 번째 확진이다.** [[project_ksaju_growth_channel_switch_2026-08-12]]의 SEO 실측(발견형 클릭 0, 브랜드검색만 클릭)과 동일 패턴. 채널을 바꿔도 0인 이유는 포맷·SEO가 아니라 **k-saju에 콜드스타트 유통 경로가 없다**는 것. 병목은 유입 최적화보다 앞단인 인지·유통 층이다.
- 권고한 다음 수 3개: ①Reddit 게시 재상신(8/12 기준 47일째 대기, 병목=게시 안 함) ②릴스로 콜드스타트(기존 daily-bg 아트 재사용, media-head 재투입) ③계정 건강도 진단(자동게시만 도는 계정의 저품질 분류 의심). 캐러셀 개발 3개 레이아웃은 릴스 소재로 재사용되므로 완주하되 우선순위는 뒤.
