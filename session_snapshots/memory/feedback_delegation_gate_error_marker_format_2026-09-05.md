형 지시(2026-09-05, [엔블 005-04] 스레드) — 이슈 스레드가 덱스·제나 상태메시지로 빠르게 채워지면서 클로의 "위임관문에 막혔습니다" 보고가 묻혀서 형이 놓치는 일이 반복됐다. 형이 눈에 띄는 고정 헤더를 요청함:

```
🟥🟥🟥🟥🟥 위임 관문 오류 🟥🟥🟥🟥🟥
```

**Why**: 🟪(결재요청)와 마찬가지로 색깔·이모지 반복 패턴이 스크롤 중에도 시각적으로 즉시 식별된다. 텍스트만으로는("죄송한데 다시 막혔습니다") 다른 팀원 메시지 사이에 묻힌다.

**How to apply**: `.claude/hooks`의 위임관문이 Edit/Write를 반려할 때마다, 그 사실을 디스코드에 보고하는 메시지 맨 위에 이 헤더를 붙일 것. [[feedback_approval_request_format_purple_card]]와 짝 — 결재요청=🟪, 위임관문 오류=🟥.

**★추가(같은 날, 형 재지시)**: 헤더만으론 부족하고, 형이 **그대로 채팅창에 쳐야 할 정확한 문구를 따옴표로 명시**할 것. 예: `형이 채팅창에 그대로 쳐주셔야 할 문구: "네가 직접 수정해"`. "부탁드립니다"처럼 애매하게 쓰면 형이 정확히 뭘 입력해야 할지 몰라 "승인"·"완료" 같은 다른 말을 쓰게 되고, 그러면 관문이 다시 안 풀린다(정규식이 "직접 수정" 패턴만 인정, [[reference_delegation_gate_bash_script_workaround_2026-09-01]] 참고).
