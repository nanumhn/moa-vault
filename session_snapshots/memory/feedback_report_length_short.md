형 지시 (2026-07-31 05:27): **"어렵다. 간략하게 정리해"**

**Why:** 라벨 수정·GPT 배선·쇼츠 실패를 각각 20~30줄짜리 보고로 연달아 보냈다. 파일명·줄번호·`recordDraft` 같은 내부 용어가 그대로 들어갔고, 형은 결정하러 왔는데 읽는 데만 시간이 들었다. 길게 쓰는 게 성실한 게 아니라 **형 일을 늘리는 것**이다. 내가 아는 걸 다 보여주려는 습관이 원인.

**How to apply:**
- 기본 형태 = **끝난 것 / 못한 것 / 하는 중** 3~4줄 + **형이 답할 것** 목록. 그게 전부.
- 파일명·줄번호·함수명은 형 보고에 쓰지 않는다. 물어보시면 그때.
- "왜 그런지" 설명은 형이 물어봤을 때만. 결과부터.
- 길게 써야 할 것 같으면 그건 대개 **내가 정리를 덜 한 것**이다. 한 번 더 줄여라.
- 예외: 형이 결정하려면 근거가 필요한 경우(비용·되돌릴 수 없는 조치)는 근거를 붙이되 짧게.
