## 이번 세션에서 확인된 유용한 사실
- **oEmbed는 우리 유튜브 채널 검증에 못 쓴다** — 채널 영상 전부 401, 외부 공개영상은 200. 도구를 안 의심했으면 정상 영상을 실패로 오진할 뻔했다. YouTube Data API `getVideoStatus`를 쓸 것.
- **PS5.1 `Out-File -Encoding utf8`은 BOM을 붙인다** — `obsidian.json`에 BOM이 있으면 볼트 등록이 통째로 무시된다. 반대로 **PS 스크립트 자신은 BOM이 있어야** 한글이 안 깨진다.
- 옵시디언 신규 설치는 **플러그인 신뢰 대화상자** 때문에 Dataview가 안 돈다. UI Automation은 Electron 창을 못 잡아 좌표 클릭으로 처리.
- **랩실에 자동 백업이 5~20분마다 돈다**(`vault backup: ... DESKTOP-xxxx` 커밋). 클로 커밋과 겹칠 수 있다.
