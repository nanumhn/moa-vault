> "클로는 코드 수정 배정하지말고, 테스트 위주로하고, 제나가 코드 담당을 한다."

**Why:** 이 지시 직전에 클로가 다리 멘션 버그를 **직접 고쳐서** 커밋했다(`b81c705`). 고친 사람이 검증까지 겸하면 생성과 검증이 한 사람에게 붙는다 — 쉐어룰이 계속 경계하는 구조다. 역할을 갈라 코드는 제나, 검증·테스트는 클로가 맡게 한 것.

**How to apply:**
- 코드 수정 과제가 오면 **내가 짜지 않는다.** 제나에게 넘기고(멘션 필수), 나는 완료 기준·테스트·음성 대조·실측 검증을 맡는다.
- 진단·원인 규명·소스 열람은 계속 내 일이다(막힌 지점을 찾아 제나에게 넘기는 것까지).
- 배정 자체는 덱스가 한다 — 내가 먼저 나서서 배정하지 않는다.
- 형이 나에게 직접 "고쳐"라고 지시하면 그건 예외지만, 그때도 검수는 반드시 남에게 붙인다.
