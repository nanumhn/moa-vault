2026-07-08 형이 지적: "결과 검사/검토/검증 담당(=서지안)이 있었는데 왜 안 거쳤냐." 그날 서진(카드원복·캡션·sitemap·SafeBrowsing진단)·서아·나라 산출물을 내가 **서지안 검수 게이트를 건너뛰고** 바로 형에게 보고했음. 서진이 스스로 빌드·라이브 검증을 했지만 그건 "만든 사람의 자기검증"이고, 서지안의 **독립검수(생성≠검증)**는 별개인데 생략함.

**Why:** 형이 만든 조직 체제의 핵심 = 생성(본부장)과 검증(검수관)의 분리. qa-lead-jian은 모든 본부장 산출물이 형에게 올라가기 전 마지막 관문. 자기가 만든 사람이 "다 됐다"는 건 편향이 있어서, 독립 검수관이 완료기준으로 판정해야 미완·결함이 걸러진다. 이 게이트를 건너뛰면 검수관을 둔 의미가 없어지고, 형이 미완을 직접 잡는 상황(형은 결재만 해야 하는데)이 재발한다.

**How to apply:**
- 본부장 산출물(코드·배포·기획·콘텐츠) → **서지안(qa-lead-jian) 독립검수 → 형 보고** 순서 준수. 빠른 대화 흐름이라도 생략 금지.
- 특히 라이브 반영·배포되는 코드(카드·캡션·sitemap 등)는 반드시 검수 게이트.
- 서지안은 판정(PASS/조건부/FAIL)만 하고 직접 수정 안 함 → FAIL이면 담당 본부장에게 구체적 보완사항과 반려 → 재검수 → 통과 후 보고.
- 자잘한 대화·단순 정보응답은 게이트 불필요. 게이트는 "본부장이 만든 산출물"에 적용.
