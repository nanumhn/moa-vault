## 알아둘 것
- **윈도우 터미널이 오래 떠 있으면 한글 입력기가 물린다** → 창 껐다 켜면 풀림. 설정·키보드 문제로 오진하기 쉽다([[reference_wt_ime_stuck_restart_2026-08-23]])
- 로그온 기동작업 중 **`클로드 코드 디스코드 연결` 만 RunLevel=Highest**(관리자). 나머지는 Limited. 이 권한 차이가 오늘 여러 증상의 뿌리였다.
- **창 경유 판정법**: 답에 나오는 작업 폴더 경로. 창=`dex-workspace`/`jena-workspace`, headless=`D:\Develop`
- **시험 메시지엔 번호를 붙인다**(시험5, 시험9…). 같은 문장으로 여러 번 보내면 창 화면만으로 건별 구분이 안 돼 오판한다.
