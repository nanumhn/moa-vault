2026-08-12 23:46 형이 이메일 발신자명이 "Moa Blog"(클로가 메일 구현 때 임시로 넣은 이름, 정식 결정 아니었음)로 나가는 걸 보고 정식 이름을 정하자고 함. 클로가 "nBlog"(엔블로그)/"블로그모아"/"나눔블로그" 3안 제시, 형이 "클로 추천으로" 위임 → **nBlog(엔블로그)로 확정**.

**Why**: 도메인이 이미 nblog.nanumn.com으로 확정돼 있어서([[project_nblog_saas_account_domain_decision_2026-08-10]]) 브랜드명을 도메인과 일치시키면 나중에 헷갈릴 일이 없음. k-saju처럼 "Moa" 접두어 없이 독립 브랜드로 가는 방향과도 일관됨.

**How to apply**: 메일 발신자명("Moa Blog" → "nBlog"), 랜딩페이지, 앱 내 UI 문구, 초대 안내 메시지 등 사용자 노출 텍스트 전체에 "nBlog"(한글 표기는 "엔블로그")로 통일해서 반영할 것. 아직 전체 반영 전 — 로그인알림메일 기능 추가하면서 같이 처리 예정([[project_nblog_saas_email_smtp_missing_2026-08-12]] 후속).
