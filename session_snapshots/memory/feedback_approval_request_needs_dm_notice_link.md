병합·배포·재시작 같은 결재 요청은 [[feedback_approval_request_format_purple_card]] 규칙대로 **해당 이슈 스레드에** 🟪 카드로 올린다.

**여기서 끝내지 않는다.** 카드를 올린 직후, **형 대화방(chat_id 1501858476362829834)에도** 짧게 알린다:

```
결재 승인 요청드렸습니다.
<그 카드 메시지의 discord.com/channels/... 링크>
```

이슈 스레드는 형이 늘 보는 채널이 아니라서, 카드만 거기 두면 형이 못 찾는다(2026-08-27~28 밤 실제로 여러 번 "요청 메시지를 찾기 힘드네" / "어떤 요청이지?" 소리를 들었다). 대화방 알림이 그 다리 역할을 한다.

**Why:** 2026-08-28 형 지시 — *"결제 승인 요청을 할 때 해당 이슈에도 일반승인 요청하는 것처럼 형식을 갖춰서 '결재 승인 요청드렸습니다' 하고 결재 승인이 등록된 텍스트 링크를 함께 첨부해"*. 덱스가 승인 카드에 "어디서" + 원문 permalink 를 넣는 것과 같은 모양이다.

**How to apply:**
1. 이슈 스레드에 🟪 카드 올림 → 메시지 id 확보
2. 링크 조립: `https://discord.com/channels/1283928656363782184/<스레드id>/<메시지id>`
3. 형 대화방에 "결재 승인 요청드렸습니다.\n<링크>" 전송
4. 스레드가 없는 결재(대화방에만 올리는 것)는 이미 그 자리에 있으니 이 절차 불필요
