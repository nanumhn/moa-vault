형이 반복 강조: 모아 스튜디오의 모든 제품/기능은 **"사용자에게 진짜 도움이 되는 서비스"**여야 한다. (2026-06-15, "사용자에게 도움이 되는 서비스를 해야지~!!!" / "기억하자~!")

**Why:** 결제 유도 꼼수로 단기 매출을 짜내는 게 아니라, 유저가 진짜 가치를 느껴 자연스럽게 쓰고 유지하게 하는 게 형의 방향. 그래야 월 1,000만원도 지속 가능. [[project_3_saju_global]]

**How to apply:**
- 새 기능 설계 시 항상 먼저 답할 것: "이걸로 user가 뭐가 좋아지나?"
- 금지: 다크패턴, 가짜 희소성("N명 남음"), 공포 마케팅(불안 조장 후 결제 유도), 강제·기만적 구독 갱신.
- 구독 가치는 실질 효용으로(예: saju 데일리 카드 = 매일 진짜 도움되는 오행 기운·조언, 협박조 아님).
- 회의 팀 briefing에도 이 원칙을 핵심으로 박는다(saju_subscription 팀에 반영함).
- 카피 톤: 따뜻하고 실용적, 불안 조장 X.
