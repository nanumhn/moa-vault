**"광고가 너무 많다"의 손잡이는 템플릿이 아니라 애드센스 자동광고 설정에 있다.** 2026-07-30 형 지적("포스팅 내용을 제대로 보기 힘들 정도")으로 찾음.

## 어디에 있나 (묻히기 쉬운 위치)
```
adsense.google.com → 사이트 → american-todayz.com 행의 [수정]
  → 인페이지 형식 → ★고급 설정 (접혀 있음)
      · 페이지당 최대 광고 수      슬라이더 6~16
      · 페이지의 광고 간 최소 간격  슬라이더 0~60  ★값이 클수록 간격이 좁다(역방향)
                                   0 = 1000px(최대) / 9 = 530px / 20 = 220px
      · 기사 페이지에서 더 많은 광고 게재위치 찾기   ← 켜져 있으면 본문을 더 쪼갠다
  → 오버레이 형식 → 앵커 / 사이드레일 / ★모바일 전면광고(로드 중 전체화면)
```

## 바꾼 값과 실측 효과 (모바일 390px, 같은 글, 같은 방법)
```
설정:  최대 8→6개 · 간격 530→1000px · 전면광고 OFF · 추가 게재위치 찾기 OFF
결과:  본문 안 광고 4→2개 · 본문 안 광고높이 1560→780px
       전체 광고높이 3405→2443px · 페이지 비중 29→22% · 앵커 285→103px
```
반영까지 **최대 1시간**이라고 애드센스가 안내한다. 저장 직후 재보면 옛 숫자가 나온다.

## 함정
- **자동광고는 로드마다 개수가 흔들린다.** 한 번 잰 값으로 "정확히 N개"라고 보고하지 말 것.
- **파이프라인·템플릿에는 본문 광고 코드가 없다**(전수 확인). 본문을 끊는 건 전부 자동광고다.
- 정적 위젯 3개(사이드바1+푸터2, slot 9111240661·8402687860·3240801031)는 자동광고와 **별개**라 애드센스 설정으로 안 줄어든다. 테마>맞춤설정>가젯에서 끄려 했으나 **저장이 반영되지 않았다(미해결)**.
- **★CSS로 광고를 숨기지 마라.** 요청은 나가는데 노출은 안 되는 상태 = 정책 위반 소지. 이 pub ID는 blog.k-saju.me 와 공유라 한쪽 사고가 양쪽을 죽인다.
