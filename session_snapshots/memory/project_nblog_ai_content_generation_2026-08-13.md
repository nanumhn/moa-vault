nBlog 베타 사용자가 "본문 자동생성 안 되냐"고 문의 → 형이 즉석에서 스코프를 확정하며 cto-seojin에게 설계+견적 지시함(2026-08-13).

**확정된 스코프**:
- 입력: 시트에 키워드/프롬프트
- 출력: nBlog 문법(문단/소제목/인용구/이미지, **영상 제외**) 본문 초안
- **완전자동발행 아님** — "검토 대기" 상태로 만들어 사용자가 검토 후 직접 발행(신뢰 쌓이면 나중에 완전자동 옵션 추가는 미래 과제)
- 텍스트: 로컬 LLM(qwen2.5-7B) 품질 부족 판단 → 아투(atz-pipeline)처럼 GPT 위주+로컬 폴백 방식 재사용
- 이미지: **Pexels(무료) 우선 → 없으면 AI생성(GPT/Flux) 보완** — 아투에 이미 Pexels 연동 있음(2026-07-26)
- 비용: 무료 아니고 유료 애드온 가능성 높음(월 N회+초과 크레딧)

**Why**: 완전자동보다 "사용자 키워드 지정+검토발행"이 책임소재·비용통제·환각리스크 면에서 안전하다고 클로가 제안, 형이 채택. 아투가 이미 겪은 환각(2026-07-27 수리)·GPT폴백품질(2026-08-07) 문제를 반드시 같은 게이트로 방어해야 함.
**How to apply**: 다음 세션에서 이 기능 이어받으면 위 스코프(영상제외/Pexels우선/검토대기)가 확정 요구사항. cto-seojin이 설계+견적 작업 중(2026-08-13 착수) — 완료되면 형 결재 후 실제 구현 단계로 넘어감, 그때 qa-lead-jian 게이트 필수.

**★2026-08-13 설계+견적 완료**(`D:\Develop\nblog-saas\docs\ai-draft-design.md`, 커밋8be0740, push안함): Phase1(텍스트만) 17일 / Phase1+2(+이미지) 25일. 원가 ~50원/편(100명×1일1편=월15만원), **AI생성이미지는 원가4배(월65만원)라 상위애드온 권고**. "검토대기"는 발행후보 SQL이 DRAFT status를 애초에 안 걷어가서 **공짜로 이미 확보됨**(새 상태 불필요). 스키마도 이미 설계돼있었음(ContentSource.AI_DRAFT 등).

**형이 요청한 "아투 GPT 그대로 재사용" = 불가능으로 확인됨**: 아투 GPT는 API가 아니라 형 개인 ChatGPT계정 브라우저 조종 방식이라 ToS위반+동시1명+형PC꺼지면 서비스중단 — API로 새로 짜야함. **환각방지 게이트도 방향전환 필요**: 아투 게이트 핵심="긁어온 원문과 대조"인데 nBlog은 원문이 없어서 원리적으로 그 검사가 불가 → 차단 대신 "형광펜"(수치·날짜 노란표시, 사용자확인) + 가짜인용문·의료법률단정만 차단.

**★★2026-08-13 정정 — UA버그는 오보였음(cto 자체 재현 후 철회)**: ~~agent/src/main/publish.ts:171 이미지다운로드 fetch에 UA헤더 없음 → Pexels 403~~ **실측 결과 UA 없어도 200 정상다운로드(1.6MB, JPEG헤더 확인) — 아투 stock.mjs 주석의 "등"을 과잉해석한 cto의 오독이었음.** 막히는 건 Python-urllib뿐, Node/Electron/curl/브라우저 UA 전부 통과. **릴리스 안 함, publish.ts 무수정.** cto가 설계문서(cb4e8ba)와 아투 stock.mjs 주석(ea072ae, 실측범위로 좁힘) 둘 다 정정 커밋. 형에게 "지금 바로 고칠게요"라고 잘못 보고했던 것 정정 필요 — 향후 이 파일 다시 볼 때 UA 버그는 없는 걸로 취급할 것.
**구현시 반드시 지킬 함정**: AI가 본문 채우면 contentHash 바뀌는데 sheet-sync가 해시로 행매칭 → 같은 글 무한증식 위험. AI초안 해시는 시트파싱값 고정+재계산금지.
