형이 2026-08-26 07:56 KST에 물었다: *"'쟀습니다.' 라는 단어를 자주 사용하던데, 무슨 뜻이야?"* → 설명 후 형 확정: ***"'확인했습니다.' 로 하자."***

**Why:** 클로가 "추측이 아니라 직접 측정했다"를 강조하려고 '재다(측정하다)'의 과거형 **"쟀습니다"** 를 습관적으로 써왔는데, 형에게는 뜻이 바로 안 와닿는 어색한 표현이었다. 근거 표기([확인] 태그·괄호 근거)를 아무리 정확히 붙여도 **형이 그 문장을 못 읽으면 소용이 없다.**

**How to apply:**
- ❌ "쟀습니다" / "재보니" / "기간을 재니" / "다시 쟀습니다"
- ✅ **"확인했습니다"** / "직접 확인해 보니" / "측정했습니다"
- 디스코드 보고·랩실 일지·이슈 포럼 글 전부 해당. [[feedback_report_length_short]] · [[feedback_verified_facts_only]] 와 같은 층의 규칙(전달 방식)이다.

## 2026-08-27 — 반쪽만 고쳐서 형이 또 지적했다

형이 *"'재러' 대신 '확인하러' 로 변경하기로 했지."* 라고 다시 짚었다.
클로는 **`쟀습니다` 한 형태만** 안 쓰기로 하고, **같은 동사의 다른 활용은 그대로 썼다**:
`재러 갑니다` · `재겠습니다` · `잽니다` · `재보니` · `다시 재라` — 그날 오전 내내 계속 썼다.

**★교훈: 낱말 하나를 금지하면 활용형으로 새어 나간다. 어간 단위로 막아야 한다.**
(같은 실수를 관문에서도 했다 — 펜스를 막았더니 인용줄로, 인용줄을 막았더니 인라인 코드로 새어 나갔다. 같은 모양의 실수다.)

**금지 = 동사 '재다' 전체.** 바꿔 쓰는 말:
```
쟀습니다     → 확인했습니다
재러 갑니다   → 확인하러 갑니다
재겠습니다    → 확인하겠습니다
잽니다        → 확인합니다
재보니        → 확인해 보니
다시 재라     → 다시 확인해라
```
