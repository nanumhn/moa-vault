형 지시(2026-08-09, 발행 에이전트 테스트 중): 텍스트만으로는 부족하고, 발행되는 글은 **멀티미디어(이미지·링크·동영상)를 적절히 섞고, SEO 관점의 헤드라인 구조(H1/H2급 서식)와 태그**까지 갖춰야 한다.

**Why:** "요즘에 사람들한테 보여주려면 텍스트만 가지고는 힘들어" — 단순 텍스트 발행은 안 된다는 형의 명확한 품질 기준.

**How to apply:**
- 지금(2026-08-09) 진행 중인 cto-seojin의 발행 에이전트 4라운드 실측에 이미지·링크·동영상 삽입, 헤드라인 서식, 태그 필드가 기술적으로 가능한지 확인 지시함(에이전트가 갖춰야 할 "능력").
- **다음 단계**: 실제 콘텐츠 작성 시 이 기준을 지키는 규칙은 content-head-seoa(콘텐츠제작본부장) 영역 — 나중에 실제 글 생성 파이프라인 붙일 때 "멀티미디어 비율·SEO 헤드라인/태그 체크리스트"를 content-creation 스킬이나 completion-gate에 반영할 필요 있음(아직 미반영, 할일로 남음).
