2026-07-29 전수 실측(238편, OAuth `tools/youtube-publish/token.json`). 형 질문 "잘 키우면 큰 성과가 있을까?"의 근거.

**채널 실측 (2026-07-29)**
```
개설 2025-03-23 · 공개 234편 + 비공개 4편 · 누적 239,966회 · 구독 154명
2025-03~05  230편  237,168회  ← 누적의 98.3%
2025-06~2026-06    공백 14개월
2026-07       8편    4,100회  ← 우리 파이프라인 (공개 4 / 비공개 4=07-27 테스트 잔여물)
```

**결론 3가지**
1. **광고수익 라인은 성립 안 한다.** YPP 문턱=구독 1,000 + 90일 쇼츠 1,000만 조회(하루 11.1만회). 그 문턱을 **넘어도** 쇼츠 RPM $0.01~0.07이라 월 5~33만원(후하게 finance급이어도 70만). 목표 2,000만원의 한 자릿수 %. → 조회수를 KPI로 잡으면 안 된다.
2. **채널은 안 죽었다.** 2025-04 편당 평균 1,178회 vs 재가동 4편 평균 1,025회 — 14개월 방치 후에도 동일 수준 배급. 페널티 없음이 확인된 자산.
3. **진짜 값어치는 B2B 쇼케이스.** 주 사업인 쇼츠 납품(편당 5~15만원 × 월 100편 = 500~1,500만원)이 광고수익의 20~200배. 지표는 조회수가 아니라 "무사고 자동 발행 편수".

**숨은 경고 지표:** 누적 24만 조회 → 구독 154명(**1,558회당 1명**), 238편 → 댓글 88개. 영상은 소비되고 채널로는 안 남는다. "잘 키우면"의 반례.

**측정 제약:** 이 토큰에는 yt-analytics 스코프가 없다(`Request had insufficient authentication scopes`). 현재 일일 트래픽·시청시간·구독증감은 못 본다 — 위 월별 집계는 **업로드 시점 기준 누적**이지 현재 유입이 아니다. 필요하면 재인증으로 스코프 추가.
