2026-07-29. 형 지시("고유관점 켜고 퀄리티 올려라")로 파고들다 창작의 발원지를 찾았다.

**원인은 모델이 아니라 프롬프트 두 줄이었다.**
1. `generate.mjs` 확장 패스가 **"'한국에는 어떤 영향' 섹션은 산업별(반도체·자동차·배터리·플랫폼·수출 등)로 구체화하라"**고 산업 이름까지 불러줬다. 뉴스가 기념사든 외교든 칸은 남으므로 모델은 **지어내서 채웠다.**
2. 호출부가 근거량에 맞춰 계산한 `effectiveTarget`(환각 방지 하향치)이 **expandArticle에 전달되지 않았다.** 1,600~1,800자가 함수 안에 상수로 박혀 있어, 로그만 "하향"이라 찍히고 모델은 계속 1,600자를 요구받았다. **2026-07-27 사고 후 세운 방어막이 한 번도 작동한 적이 없었다.**

**실측 증거 (같은 근거로 재생성 4회): 858·706·833·686자.** 라이브 원본은 1,600자였다 — 차이가 전부 창작. 원문 대조는 더 결정적: 자동차·배터리·플랫폼·수출·공급망이 **원문 등장 0회**인데 기사엔 각 5회.

**수정** — 산업 목록 제거 + "없으면 직접 영향 없다고 쓰고 끝내라" 탈출구 + target 인자 전달 + 지시문 길이 실측(상수 추정 금지) + `qualityGate(minLen)`·`rankCandidate(cap)`를 **자연 분량**(후보 길이 중앙값) 기반으로. 회귀 테스트 `expand-prompt.test.mjs` 6개 신설. ※미커밋(형 요청 없었음).

**라이브 복구 5편** (전부 posts.patch·제목/라벨 재조회 확인): 정전협정·미-이란·관세상시·12.5%·애플마이크론. 헤지 21.7→1.9 / 16.8→1.6 / 14.8→1.4 / 18.8→1.2. 셋은 게이트 전 항목 PASS.

**가장 중요한 발견:** 원문에 있던 진짜 숫자(15% 상한·12.5%·제조업 수출 -9.3%·브렌트유 87달러)를 **한 번도 안 쓰고** 지어낸 회사명(현대차·LG에너지솔루션·네이버)을 썼다. 근거가 없어서 지어낸 게 아니라 **칸을 채우라는 지시가 근거보다 셌다.**
