`.claude/hooks/guard-report.mjs` **141~155행 `ownClaimText()`** 는 검사 전에
펜스(```)·인용(>)·**인라인 코드(`` `...` ``)를 전부 지운다**(151행 `raw.replace(/`[^`]*`/g, " ")`).

그래서 근거를 `` `[확인: ...]` `` 처럼 **백틱으로 감싸면 G4에는 그 근거가 존재하지 않는다.**
본문에 `원인은`·`때문` 같은 낱말만 남아 `🟠 [G4] 원인 주장 문제 — 아무 표시도 없다` 로 반려된다.

**2026-09-09 실측**: 아투 보고를 쓰면서 근거 6개를 전부 백틱으로 감쌌더니 **2회 연속 반려**됐다.
백틱을 벗기고 `[확인: atz_pipeline.log 를 UTF-16 디코드해 …]` 를 **맨 줄에 그대로 두자 통과**했다.

**How to apply**: 형께 보내는 보고에서 **최소 한 개의 `[확인: 근거]` 는 백틱 없이 평문으로** 쓴다.
파일명·경로를 백틱으로 감싸고 싶으면 근거 표기와 분리해서 쓴다 —
`[확인: 원장 직접 조회]` 를 평문으로 두고, 파일명은 다른 줄에서 백틱 처리.

**주의 — 이건 딜레마다.** 백틱 안에 경로를 쓰지 않으면 [[reference_guard_report_g8_path_citation_bug_2026-09-05]]
(G8이 방금 읽은 파일 경로 인용을 반복 거부)에 걸릴 수 있다. G4는 백틱을 지워서 막고,
G8은 경로 때문에 막는다. **둘을 동시에 피하는 자리 = 근거는 평문으로 서술하고 절대경로는 아예 안 쓰는 것.**

근본 수리(관문끼리 서로 물리는 문제)는 형 결재 대상이고 `harness-pending.md` 에 올릴 건이다.
