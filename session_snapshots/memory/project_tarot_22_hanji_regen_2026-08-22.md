## ★화풍 규칙 — 형 확정(2026-08-22 23:51 "추천대로 가")
**왕·관리·권위 계열 카드는 곤룡포·중국 사자상 금지, 조선 관복으로 간다** — 단령(목이 둥근 관복) + 사모(양옆으로 날개처럼 뻗은 검은 관) + 가슴 흉배. 짐승은 **해태**로: 외뿔 하나·몸에 비늘·목에 방울, **사자갈기 아님**.
**★이 규칙은 ChatGPT 대화 메모리에 이미 저장됐다** — *"규칙에 반영했어. 앞으로 왕·관리·권위 계열 카드는 중국 황제풍 요소를 배제하고, 조선 단령 + 사모 + 흉배를 기본으로…"* 응답으로 확인. **이어서 할 땐 다시 안 적어도 된다.**
단, 규칙만 저장하고 그림은 안 그리는 경우가 있으니 **"지금 그려줘"라고 따로 시켜야 한다**(실제로 한 번 그랬다).
