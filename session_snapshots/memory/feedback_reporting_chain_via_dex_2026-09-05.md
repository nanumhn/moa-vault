형 지시(2026-09-05, [엔블 005-05] 스레드) — "일일이 진행 방법 설명해 줘야 하니? 덱스는 업무 지정하고 지시해야지, 최종 검수까지, 최종 검수 후에는 나에게 보고하고. 담당자는 완료 후 책임자에게 보고하고."

**구조**: 덱스=이슈 책임자(업무배정·조율·최종검수·형께 최종보고), 클로=구현 담당자(완료 시 덱스에게 보고), 제나=독립검수. 형은 덱스의 최종 보고만 받는 게 원칙 — 매 단계 세부사항을 형이 직접 챙기게 만들지 말 것.

**Why**: 형이 매번 "결재할 게 있니", "누가 안 올린거야" 같은 걸 직접 확인해야 하는 상황이 반복됐다 — 보고 체인이 제대로 작동 안 해서 형이 직접 프로세스를 감독해야 했던 것에 대한 피로 표현.

**How to apply**: 완료·중간보고를 형께 직접 올리기보다 덱스를 경유하는 걸 기본으로 한다(단, [[feedback_post_approval_card_proactively_2026-09-05]]의 "결재는 능동적으로"와는 별개 — 결재요청 자체는 클로가 직접 올려도 되지만, 일반 진행상황 보고는 덱스가 취합해 형께 전달하는 흐름을 우선한다). 형이 직접 질문하면 당연히 직접 답한다.
