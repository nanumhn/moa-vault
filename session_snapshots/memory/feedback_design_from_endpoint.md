**형 지시(2026-07-27):** *"이건 블로그 시작할 때 고려해서 진행 했어야 하지 않니? 미래를 생각하면 기획, 실행이 되길 바래."*

**Why:** blog.k-saju.me를 44편 쌓은 뒤에야 애드센스 요건이 하나도 안 맞는 걸 발견했다. 넷 다 **시작할 때 정했어야 할 것**이다:
```
글 분량 550단어      → 심사 기준 미달 (900~1,200 필요)
개인정보처리방침      → 없었음. 애드센스 즉시 탈락 사유인데 44편 쌓을 때까지 부재
애드센스 코드         → 0건. 글은 매일 쌓이는데 수익이 구조적으로 0원
ads.txt              → 404
```
아투도 같은 모양이었다 — 186건 발행 후에야 **출처 표기 0%**(Google 「Scraping」 직격)를 발견했다. 즉 우연이 아니라 **"만들고 나서 문제를 찾는" 순서 자체가 문제**다.

**How to apply — 새 자산·서비스·자동화를 시작하기 전에 이 순서로 적고 시작한다:**
1. **이걸로 어떻게 돈을 버나** (애드센스 / 결제 / 납품…)
2. **그 관문의 합격 기준이 무엇인가** (심사 요건·플랫폼 정책·SEO 최소선)
3. **그럼 산출물 1개의 스펙은 무엇인가** (분량·출처·오리지널리티·필수 페이지)
4. **자동화가 그 스펙을 지킬 수 있나** — 못 지키면 게이트로 강제한다

**핵심: 쌓인 다음에 고치면 비용이 N배다.** 44편·186건을 소급 보강하는 것과, 1편째부터 기준을 지키는 것의 차이다. 자동 발행이 돌고 있으면 **스펙 수정이 최우선** — 안 고치면 기준 미달분이 계속 쌓인다.
